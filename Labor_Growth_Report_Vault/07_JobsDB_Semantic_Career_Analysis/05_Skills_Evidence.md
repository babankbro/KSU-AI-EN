# หลักฐาน Technical และ Soft Skills

## วิธีอ่าน

ตารางแสดง Skills ที่พบสูงสุดในงานซึ่งมี `classifiedMatches` ของ C นั้น ตัวเลขในวงเล็บคือจำนวนงานและร้อยละของงานใน C การนับหนึ่ง Skill ไม่เกินหนึ่งครั้งต่อ Job ID ต่อ C

> [!important]
> แต่ละ C มี Technical taxonomy 20 รายการที่เหมาะกับโดเมน ส่วน Soft Skills ใช้ taxonomy กลาง 10 รายการ หน้านี้แสดงรายการเด่นเพื่อใช้ตัดสินใจเชิงหลักสูตร ไม่ใช่การแทนข้อความประกาศงานทั้งหมด

## ชุดทักษะที่ควรสะท้อนในหลักสูตร

1. **แกน AI/Data/Software:** Python, SQL, ML, data pipelines, APIs, cloud, CI/CD, security
2. **แกน Industrial:** automation, PLC/SCADA, sensors, process optimization, quality, Lean, MES
3. **แกน Smart Agriculture:** precision agriculture, IoT, cloud IoT, sensors, automation, analytics
4. **แกน Decision/Product:** BI, visualization, forecasting, optimization, prototyping, product management
5. **แกน Soft Skills:** communication, English, problem solving, collaboration, analytical thinking และ stakeholder management
