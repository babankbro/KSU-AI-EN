# ⑦ Curriculum Mapping — รายวิชา ↔ PLO ↔ Skills

> ขั้นที่หก (Constructive Alignment): แมป **รายวิชาหมวดวิชาเฉพาะ** เข้ากับ **PLO1–PLO7** พร้อมเหตุผลเชิงเนื้อหาและทักษะเป้าหมาย (H/S)
> ปรับตามโครงร่างรายวิชาฉบับล่าสุด (รหัส EN-001/131/132/133/134/135) และ Master Catalog H1–H20/S1–S10 · อัปเดต 29 กรกฎาคม 2569 / 2026-07-29

## กติกาการแมป (Mapping Rules)

1. **รายวิชาทั่วไปรับผิดชอบ ≤ 3 PLOs** — ยกเว้นกลุ่ม **2.6 โครงงาน/สัมมนา** และ **2.7 สหกิจ** ที่บูรณาการหลาย PLO ได้
2. **แต่ละ PLO ต้องมีวิชารับผิดชอบ ≥ 10 วิชา**
3. **ไม่มี PLO ใดรับผิดชอบเกิน 25%** ของภาระทั้งหมด
4. เครื่องหมาย **●** = วิชานั้นรับผิดชอบพัฒนา/ประเมิน PLO นั้น (นับรวมทั้งหลักและรอง) · **Skills** อ้างรหัส H1–H20/S1–S10 จาก [[03_Target_Skills]]
5. ชุดทักษะสำหรับ Skill Transcript ใช้ **EN-AISK01–09/G1–G7** ตาม [[../05_TQF2_Academic_Drafts/11_Skill_Set_Matrix_and_KSA|Skill Set Matrix and KSA]]
