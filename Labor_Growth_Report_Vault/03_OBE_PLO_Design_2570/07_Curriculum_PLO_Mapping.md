# ⑦ Curriculum Mapping — รายวิชา ↔ PLO ↔ Skills

> ขั้นที่หก (Constructive Alignment): แมป **รายวิชาหมวดวิชาเฉพาะ** เข้ากับ **PLO1–PLO7** พร้อมเหตุผลเชิงเนื้อหาและทักษะเป้าหมาย (H/S)
> ปรับตามโครงร่างรายวิชาฉบับล่าสุด (รหัส EN-001/131/132/133/134/135) · อัปเดต 20 กรกฎาคม 2569 / 2026-07-20

## กติกาการแมป (Mapping Rules)

1. **รายวิชาทั่วไปรับผิดชอบ ≤ 3 PLOs** — ยกเว้นกลุ่ม **2.6 โครงงาน/สัมมนา** และ **2.7 สหกิจ** ที่บูรณาการหลาย PLO ได้
2. **แต่ละ PLO ต้องมีวิชารับผิดชอบ ≥ 10 วิชา**
3. **ไม่มี PLO ใดรับผิดชอบเกิน 25%** ของภาระทั้งหมด
4. เครื่องหมาย **●** = วิชานั้นรับผิดชอบพัฒนา/ประเมิน PLO นั้น (นับรวมทั้งหลักและรอง) · **Skills** อ้างรหัสจาก [[03_Target_Skills]]
