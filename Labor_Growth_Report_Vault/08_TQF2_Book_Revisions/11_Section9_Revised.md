## 9.1 บทนำและปรัชญาการบริหารคุณภาพ

แผนกลยุทธ์การบริหารคุณภาพหลักสูตรวิศวกรรมศาสตรบัณฑิต สาขาวิชาวิศวกรรมปัญญาประดิษฐ์และระบบอัจฉริยะ ระยะ 5 ปี (พ.ศ. 2569–2573) จัดทำขึ้นเพื่อกำหนดทิศทางการพัฒนาคุณภาพหลักสูตรอย่างเป็นระบบ ตั้งแต่ปีที่เปิดรับนักศึกษารุ่นแรกจนถึงปีที่บัณฑิตรุ่นแรกสำเร็จการศึกษาและเข้าสู่ตลาดแรงงาน

แผนกลยุทธ์ฉบับนี้ดำเนินงานภายใต้ปรัชญา **"ความเป็นเลิศผ่านการปรับปรุงอย่างต่อเนื่องบนฐานหลักฐาน"** กล่าวคือ การตัดสินใจเชิงคุณภาพทุกระดับต้องอ้างอิงข้อมูลผลสัมฤทธิ์ของผู้เรียนและเสียงสะท้อนจากผู้มีส่วนได้ส่วนเสีย มิใช่การคาดการณ์หรือความเห็นส่วนบุคคล

ยิ่งไปกว่านั้น แผนฉบับนี้ทำหน้าที่เป็นสะพานเชื่อมเชิงกลยุทธ์ระหว่างความต้องการจำเป็นที่วิเคราะห์ไว้ในหมวดที่ 2 ผลลัพธ์การเรียนรู้ที่กำหนดไว้ในหมวดที่ 3 และกระบวนการประเมินที่ออกแบบไว้ในหมวดที่ 8 โดยมีลักษณะเฉพาะที่ต่างจากหลักสูตรทางวิศวกรรมโดยทั่วไปประการหนึ่ง คือ **พลวัตของเทคโนโลยีปัญญาประดิษฐ์** ซึ่งมีแนวโน้มว่าทักษะราวร้อยละ 39 จะล้าสมัยภายในปี พ.ศ. 2573 อันเป็นช่วงเวลาเดียวกับที่แผนฉบับนี้สิ้นสุดพอดี การบริหารคุณภาพของหลักสูตรนี้จึงต้องให้น้ำหนักกับกลไกการเฝ้าติดตามเทคโนโลยีและการปรับปรุงเนื้อหารายวิชาเป็นพิเศษ

## 9.2 การวิเคราะห์สถานการณ์และปัจจัยเชิงกลยุทธ์

เพื่อกำหนดทิศทางเชิงกลยุทธ์ที่เหมาะสม หลักสูตรได้วิเคราะห์ปัจจัยภายในและภายนอกด้วยเทคนิค SWOT โดยอาศัยข้อมูลจากการเทียบเคียงหลักสูตรคู่เทียบ 5 แห่งในประเทศไทย ผลสำรวจความต้องการของผู้มีส่วนได้ส่วนเสีย และการวิเคราะห์ตลาดแรงงานในหมวดที่ 2

**ตารางที่ 9.1** การวิเคราะห์ SWOT ของหลักสูตรวิศวกรรมปัญญาประดิษฐ์และระบบอัจฉริยะ

| ปัจจัยภายใน | จุดแข็ง (Strengths) | จุดอ่อน (Weaknesses) |
|---|---|---|
| | **S1** หลักสูตรใหม่ พ.ศ. 2570 ออกแบบตามแนวทาง OBE ครบวงจร สอบย้อนกลับได้ตั้งแต่ความต้องการจำเป็น N1–N18 ลักษณะบัณฑิต GA1–GA5 ผลลัพธ์การเรียนรู้ PLO1–PLO7 ไปจนถึง CLO รายวิชา | **W1** เป็นหลักสูตรใหม่ที่ยังไม่มีบัณฑิตสำเร็จการศึกษา จึงยังไม่มีข้อมูลภาวะการมีงานทำและเสียงสะท้อนจากผู้ใช้บัณฑิตจริง |
| | **S2** มี **อัตลักษณ์ทางวิศวกรรม** ที่แตกต่างจากหลักสูตรสายคอมพิวเตอร์ โดยผู้เรียนต้องบูรณาการฮาร์ดแวร์ อุปกรณ์ตรวจวัด และระบบควบคุมเข้ากับปัญญาประดิษฐ์ ผ่านปฏิบัติการวิศวกรรมเชิงบูรณาการ 3 รายวิชาต่อเนื่อง ซึ่งไม่พบในหลักสูตรคู่เทียบทั้ง 5 แห่ง | **W2** ต้นทุนโครงสร้างพื้นฐานสูง ทั้งทรัพยากรคำนวณสมรรถนะสูง ระบบคลาวด์ อุปกรณ์อินเทอร์เน็ตของสรรพสิ่ง และอากาศยานไร้คนขับ |
| | **S3** โดเมนเฉพาะที่ยึดโยงพืชเศรษฐกิจและโรงงานจริงของภาคตะวันออกเฉียงเหนือ ได้แก่ ข้าว อ้อยและน้ำตาล และมันสำปะหลัง เป็นความแตกต่างที่หลักสูตรอื่นลอกเลียนได้ยาก | **W3** จำนวนอาจารย์ที่มีความเชี่ยวชาญเฉพาะด้านปัญญาประดิษฐ์เชิงสร้างและระบบเอเจนต์ยังจำกัด และเป็นสาขาที่ตลาดแรงงานแข่งขันสูง |
| | **S4** โครงสร้าง 3 แขนงวิชาบนฐานวิชาชีพบังคับร่วม 9 รายวิชา ทำให้ผู้เรียนมีทั้งฐานร่วมที่แข็งแรงและความลึกเฉพาะทาง | **W4** ยังไม่มีระบบสารสนเทศที่รวบรวมผลสัมฤทธิ์ระดับ CLO โดยอัตโนมัติ ทำให้การสังเคราะห์ผลระดับ PLO ต้องอาศัยการประมวลผลด้วยบุคลากร |
| **ปัจจัยภายนอก** | **โอกาส (Opportunities)** | **อุปสรรค (Threats)** |
| | **O1** นโยบายภาครัฐสนับสนุนชัดเจน ทั้งยุทธศาสตร์ชาติ 20 ปี แผนปฏิบัติการปัญญาประดิษฐ์แห่งชาติ และโมเดลเศรษฐกิจบีซีจี | **T1** การแข่งขันสูงจากหลักสูตรปัญญาประดิษฐ์ที่เปิดใหม่ในหลายสถาบัน โดยเฉพาะคู่แข่งในภาคตะวันออกเฉียงเหนือ |
| | **O2** ช่องว่างกำลังคนดิจิทัลของประเทศประมาณ 75,000 อัตราต่อปี และความต้องการกำลังคนทักษะสูงใน 10 อุตสาหกรรมเป้าหมายมากกว่า 1,000,000 ตำแหน่ง | **T2** เทคโนโลยีปัญญาประดิษฐ์เปลี่ยนแปลงเร็วมาก ทักษะราวร้อยละ 39 อาจล้าสมัยภายใน พ.ศ. 2573 ทำให้เนื้อหารายวิชาและอุปกรณ์ล้าสมัยได้เร็วกว่าสาขาอื่น |
| | **O3** องค์กรไทยร้อยละ 71.8 ใช้งานหรือวางแผนใช้ปัญญาประดิษฐ์แล้ว ทำให้มีสถานประกอบการรองรับสหกิจศึกษาเพิ่มขึ้น | **T3** การแข่งขันแย่งชิงบุคลากรผู้สอนกับภาคเอกชนที่ให้ผลตอบแทนสูงกว่ามาก |
| | **O4** การขาดแคลนแรงงานภาคเกษตรจากสังคมสูงวัย เป็นแรงผลักให้ภาคเกษตรอุตสาหกรรมในพื้นที่ต้องใช้ระบบอัตโนมัติและปัญญาประดิษฐ์ | **T4** ความผันผวนของจำนวนประชากรวัยเรียนที่ลดลงต่อเนื่อง ส่งผลต่อจำนวนผู้สมัครของทุกหลักสูตร |

ผลการวิเคราะห์ SWOT ถูกนำมาสังเคราะห์เป็นทางเลือกเชิงกลยุทธ์ผ่านเมทริกซ์ TOWS เพื่อกำหนดกลยุทธ์ที่ใช้จุดแข็งขยายโอกาส แก้ไขจุดอ่อน ป้องกันอุปสรรค และตั้งรับความเสี่ยง

**ตารางที่ 9.2** การวิเคราะห์ TOWS Matrix เพื่อกำหนดกลยุทธ์การบริหารคุณภาพ

| | จุดแข็ง (Strengths) | จุดอ่อน (Weaknesses) |
|---|---|---|
| **โอกาส (Opportunities)** | **กลยุทธ์เชิงรุก (SO)**<br>(S2+S3+O2+O4) พัฒนาหลักสูตรสู่ความเป็นเลิศด้าน **วิศวกรรมปัญญาประดิษฐ์เชิงบูรณาการระบบสำหรับเกษตรอุตสาหกรรม** โดยชูอัตลักษณ์ที่บัณฑิตสร้างระบบจริงได้ มิใช่เพียงพัฒนาแบบจำลอง<br>(S1+O1) ใช้ความสอบย้อนกลับได้ของกรอบ OBE เป็นจุดขายในการขอรับรองคุณภาพระดับสากล | **กลยุทธ์เชิงแก้ไข (WO)**<br>(W2+O1+O3) แสวงหาความร่วมมือกับภาคอุตสาหกรรมและหน่วยงานภาครัฐ เพื่อใช้ทรัพยากรคำนวณและสถานที่ฝึกปฏิบัติร่วมกัน ลดภาระการลงทุนของหลักสูตร<br>(W1+O3) เร่งสร้างเครือข่ายสถานประกอบการสหกิจศึกษาตั้งแต่ปีแรก เพื่อให้มีข้อมูลเสียงสะท้อนก่อนบัณฑิตรุ่นแรกสำเร็จการศึกษา |
| **อุปสรรค (Threats)** | **กลยุทธ์เชิงป้องกัน (ST)**<br>(S2+S3+T1) ชูจุดเด่นด้านอัตลักษณ์ทางวิศวกรรมและโดเมนพืชเศรษฐกิจในพื้นที่ ซึ่งหลักสูตรคู่แข่งลอกเลียนได้ยาก เป็นแกนของการสื่อสารหลักสูตร<br>(S4+T2) ใช้โครงสร้างคลังวิชาชีพเลือกที่ยืดหยุ่น เปิดรายวิชาใหม่ได้ตามแนวโน้มเทคโนโลยีโดยไม่ต้องปรับปรุงหลักสูตรทั้งฉบับ | **กลยุทธ์เชิงรับ (WT)**<br>(W3+T3) พัฒนาอาจารย์ภายในด้วยแผนพัฒนารายบุคคลและการรับรองสมรรถนะทางเทคนิค ควบคู่กับการเชิญผู้เชี่ยวชาญจากภาคอุตสาหกรรมร่วมสอน เพื่อลดการพึ่งพาการสรรหาอาจารย์ใหม่<br>(W4+T2) พัฒนาระบบสารสนเทศติดตามผลสัมฤทธิ์ระดับ CLO เพื่อให้ตรวจพบความล้าสมัยของเนื้อหาได้เร็วขึ้น |

## 9.3 กรอบการบริหารคุณภาพหลักสูตร

กรอบการบริหารคุณภาพนี้อิงตามแนวทางของสำนักงานปลัดกระทรวงการอุดมศึกษา วิทยาศาสตร์ วิจัยและนวัตกรรม และบูรณาการหลักการของ AUN-QA เพื่อยกระดับสู่มาตรฐานสากล ประกอบด้วยสององค์ประกอบหลัก ดังนี้

### 9.3.1 การวางแผนคุณภาพ (Quality Planning)

การวางแผนคุณภาพเป็นการวางรากฐานของความเป็นเลิศ โดยเริ่มจากการแปลความต้องการของผู้มีส่วนได้ส่วนเสียให้เป็นผลลัพธ์การเรียนรู้ที่คาดหวัง แล้วออกแบบกระบวนการจัดการเรียนการสอนและการประเมินให้สอดรับกัน

**กิจกรรมหลัก**

1) **การวิเคราะห์ความต้องการเชิงลึก** จัดประชุมรับฟังความคิดเห็นจากผู้มีส่วนได้ส่วนเสียในอุตสาหกรรมเป้าหมาย ได้แก่ อุตสาหกรรมข้าว อ้อยและน้ำตาล มันสำปะหลัง ผู้ประกอบการด้านเทคโนโลยี ศิษย์เก่า และเกษตรกรผู้ใช้เทคโนโลยี อย่างน้อยปีละ 1 ครั้ง ตามกลไกที่กำหนดไว้สำหรับ SH1 ถึง SH8

2) **การทบทวนผลลัพธ์การเรียนรู้** ทบทวน PLO และ CLO ให้สอดคล้องกับสถานการณ์ปัจจุบัน โดยใช้ผลการวิเคราะห์ SWOT และ TOWS เป็นฐานการตัดสินใจ

3) **การจัดทำแผนที่แสดงความเชื่อมโยง** จัดทำและปรับปรุงแผนที่แสดงความเชื่อมโยงระหว่าง PLO, YLO และ CLO ของทุกรายวิชา พร้อมระบุระดับ I, R และ M เพื่อให้มั่นใจว่าผลลัพธ์การเรียนรู้ทุกข้อมีรายวิชารับผิดชอบและมีจุดประเมินขั้นบรรลุผลที่ชัดเจน

4) **การเฝ้าติดตามเทคโนโลยีประจำปี** จัดทำเอกสารเฝ้าติดตามเทคโนโลยีอุบัติใหม่ทุกปีการศึกษา เทียบกับชุดทักษะ EN-AISK01 ถึง EN-AISK09 เพื่อระบุช่องว่างที่ต้องปรับปรุงเนื้อหารายวิชา อันเป็นกิจกรรมเฉพาะที่จำเป็นสำหรับหลักสูตรด้านปัญญาประดิษฐ์

### 9.3.2 การรักษาคุณภาพ (Quality Maintenance)

การรักษาคุณภาพคือการดำเนินงานตามแผนให้เกิดประสิทธิผลสูงสุด โดยใช้วงจร PDCA เป็นกลไกหลักในทุกระดับ ตั้งแต่การจัดการเรียนการสอนรายวิชาไปจนถึงการบริหารหลักสูตร

|---|---|
| Plan | อาจารย์ผู้สอนจัดทำรายละเอียดของรายวิชาที่ระบุ CLO กิจกรรมการเรียนรู้ และเกณฑ์การให้คะแนนที่สอดคล้องกับ PLO |
| Do | จัดการเรียนการสอนที่เน้นผู้เรียนเป็นสำคัญ ตามกลยุทธ์การสอน 5 รูปแบบในหมวดที่ 5 ควบคู่กับการเรียนรู้เชิงบูรณาการกับการทำงานผ่านสหกิจศึกษา |
| Check | ประเมินผลการเรียนรู้ตาม CLO และติดตามความก้าวหน้าของผู้เรียนอย่างสม่ำเสมอ |
| Act | นำผลการประเมินมาปรับปรุงการสอนในรอบถัดไป และจัดทำรายงานผลการดำเนินการของรายวิชา |

**การบริหารความเสี่ยง** หลักสูตรบริหารจัดการความเสี่ยงอย่างเป็นระบบ เพื่อเตรียมพร้อมรับมือกับปัจจัยที่อาจส่งผลกระทบต่อคุณภาพการศึกษา

**ตารางที่ 9.3** การประเมินและบริหารจัดการความเสี่ยงของหลักสูตร

| ประเภทความเสี่ยง | รายละเอียดความเสี่ยง | ระดับผลกระทบ | โอกาสเกิด | ระดับความเสี่ยง | มาตรการป้องกันและลดผลกระทบ | ผู้รับผิดชอบ |

| ทรัพยากร | ทรัพยากรคำนวณสมรรถนะสูงและค่าบริการระบบคลาวด์ไม่เพียงพอต่อจำนวนผู้เรียน | สูง | กลาง | สูง | จัดทำแผนการใช้ทรัพยากรร่วมระดับคณะ แสวงหาความร่วมมือกับผู้ให้บริการคลาวด์ในรูปแบบทุนการศึกษา และจัดลำดับความสำคัญของรายวิชาที่ต้องใช้หน่วยประมวลผลกราฟิก | คณะกรรมการบริหารหลักสูตรร่วมกับคณะ |
| บุคลากร | อาจารย์ที่เชี่ยวชาญเฉพาะทางลาออกไปสู่ภาคเอกชน | สูง | กลาง | สูง | จัดทำแผนพัฒนารายบุคคล สนับสนุนการเข้าสู่ตำแหน่งทางวิชาการ และสร้างเครือข่ายผู้เชี่ยวชาญจากภาคอุตสาหกรรมร่วมสอน | ผู้บริหารคณะ |

## 9.4 แผนปฏิบัติการและตัวชี้วัดความสำเร็จ

เพื่อให้การดำเนินงานตามแผนกลยุทธ์เป็นรูปธรรม จึงกำหนดแผนปฏิบัติการระยะ 5 ปี พร้อมตัวชี้วัดความสำเร็จที่มุ่งเน้นผลลัพธ์และผลกระทบ มิใช่เพียงปริมาณกิจกรรมที่ดำเนินการ

**ตารางที่ 9.4** แผนปฏิบัติการบริหารคุณภาพหลักสูตร ระยะ 5 ปี (พ.ศ. 2569–2573)

| ปีการศึกษา | กิจกรรมหลักด้านการบริหารคุณภาพ | ผู้รับผิดชอบหลัก |
|---|---|---|
| 2569 | จัดตั้งคณะที่ปรึกษาภาคอุตสาหกรรม · อบรมเชิงปฏิบัติการด้าน OBE และการเรียนรู้เชิงรุกสำหรับคณาจารย์ · เริ่มใช้วงจร PDCA ในทุกรายวิชาอย่างเป็นทางการ · จัดทำเอกสารเฝ้าติดตามเทคโนโลยีฉบับแรก | คณะกรรมการบริหารหลักสูตร |
| 2570 | เปิดรับนักศึกษารุ่นแรก · นำร่องระบบติดตามผลสัมฤทธิ์ระดับ CLO ในรายวิชาแกน · ประเมินผลลัพธ์การเรียนรู้ YLO1 ของนักศึกษาชั้นปีที่ 1 · สร้างเครือข่ายสถานประกอบการสหกิจศึกษาไม่น้อยกว่า 10 แห่ง | ประธานหลักสูตร |
| 2571 | ขยายผลระบบติดตามผลสัมฤทธิ์ระดับ CLO ให้ครบทุกรายวิชาแกน · ประเมิน YLO2 · ทบทวนเนื้อหารายวิชาแกนครั้งที่ 1 โดยใช้ข้อมูลจากคณะที่ปรึกษาภาคอุตสาหกรรม | คณะกรรมการบริหารหลักสูตร |
| 2572 | ประเมิน YLO3 · เตรียมความพร้อมเพื่อรับการประเมินคุณภาพตามเกณฑ์ AUN-QA โดยจัดทำรายงานการประเมินตนเอง · เริ่มโครงการวิจัยร่วมกับภาคอุตสาหกรรมโดยใช้โครงงานของผู้เรียนเป็นฐาน | คณะกรรมการบริหารหลักสูตรร่วมกับผู้บริหารคณะ |
| 2573 | บัณฑิตรุ่นแรกสำเร็จการศึกษา · ประเมินการบรรลุ PLO ทั้ง 7 ข้อของบัณฑิตรุ่นแรก · ติดตามภาวะการมีงานทำและเสียงสะท้อนจากผู้ใช้บัณฑิต · รับการประเมินตามเกณฑ์ AUN-QA · ประเมินผลแผนกลยุทธ์ฉบับนี้และจัดทำแผนฉบับต่อไป (พ.ศ. 2574–2578) | คณะกรรมการบริหารหลักสูตรร่วมกับผู้บริหารคณะ |

**ตารางที่ 9.5** ตัวชี้วัดความสำเร็จของแผนกลยุทธ์การบริหารคุณภาพ

| มุมมอง | ตัวชี้วัด | ค่าตั้งต้น (พ.ศ. 2569) | เป้าหมาย พ.ศ. 2573 |
|---|---|---|---|
| ผลลัพธ์การเรียนรู้ | ร้อยละของผู้เรียนที่บรรลุ PLO แต่ละข้อในระดับขั้นบรรลุผล (Mastery) | ยังไม่มีข้อมูล | ไม่น้อยกว่าร้อยละ 80 |
| | ร้อยละของบัณฑิตที่ได้งานทำในสาขาที่เกี่ยวข้องหรือเป็นผู้ประกอบการภายใน 1 ปี | ยังไม่มีข้อมูล | ไม่น้อยกว่าร้อยละ 90 |
| | ร้อยละของโครงงาน EN-134-404 ที่ส่งมอบระบบต้นแบบใช้งานได้จริงแก่สถานประกอบการหรือชุมชนเจ้าของโจทย์ | ยังไม่มีข้อมูล | ไม่น้อยกว่าร้อยละ 70 |
| ผู้มีส่วนได้ส่วนเสีย | คะแนนความพึงพอใจของผู้ใช้บัณฑิตต่อสมรรถนะของบัณฑิต | ยังไม่มีข้อมูล | ไม่น้อยกว่า 4.2 จาก 5.0 |
| | จำนวนสถานประกอบการที่นำเทคโนโลยีหรือแนวคิดจากโครงงานของผู้เรียนไปใช้จริง | ยังไม่มีข้อมูล | ไม่น้อยกว่า 3 องค์กร |
| | จำนวนสถานประกอบการในเครือข่ายสหกิจศึกษา | 0 แห่ง | ไม่น้อยกว่า 25 แห่ง |
| กระบวนการภายใน | ร้อยละของรายวิชาที่ดำเนินการตามวงจร PDCA ครบถ้วนและมีหลักฐานในรายงานผลการดำเนินการของรายวิชา | ยังไม่มีข้อมูล | ร้อยละ 100 |
| | ร้อยละของรายวิชาแกนที่ได้รับการทบทวนความทันสมัยของเนื้อหาในรอบปีการศึกษา | ยังไม่มีข้อมูล | ร้อยละ 100 ทุกปีการศึกษา |
| | ระบบติดตามผลสัมฤทธิ์ระดับ CLO ที่ให้ข้อมูลสนับสนุนการตัดสินใจของอาจารย์ผู้สอนได้ | ยังไม่มีระบบ | ใช้งานเต็มรูปแบบ |
| การเติบโตและพัฒนา | จำนวนผลงานวิชาการหรือนวัตกรรมที่เกิดจากความร่วมมือระหว่างคณาจารย์และผู้เรียน | ยังไม่มีข้อมูล | ไม่น้อยกว่า 10 ชิ้นต่อปี |
| | สัดส่วนคณาจารย์ที่ผ่านการอบรมหรือได้รับการรับรองสมรรถนะด้านเทคโนโลยีปัญญาประดิษฐ์ | ยังไม่มีข้อมูล | อย่างน้อย 1 หลักสูตรต่อคนต่อปี |
