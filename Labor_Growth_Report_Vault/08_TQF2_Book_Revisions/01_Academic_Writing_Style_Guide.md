# คู่มือรูปแบบการเขียนเชิงวิชาการของเล่มหลักสูตร

> สังเคราะห์จากเล่ม มคอ.2 ฉบับ `3.หลักสูตรวิศวกรรมปัญญาประดิษฐ์และระบบอัจฉริยะ.docx` โดยวิเคราะห์หมวดที่ 1–4 ซึ่งเป็นส่วนที่เขียนเสร็จสมบูรณ์และผ่านการทบทวนแล้ว
> จัดทำ 30 กรกฎาคม 2569 / 2026-07-30
> ใช้เป็นมาตรฐานเดียวสำหรับการเขียนและแก้ไขทุกหมวดของเล่มหลักสูตร เพื่อให้สำนวนทั้งเล่มเป็นเนื้อเดียวกัน

## 1. ระดับภาษาและน้ำเสียง

หลักสูตรใช้ภาษาไทยระดับทางการเชิงวิชาการ เขียนด้วยประโยคความรวมที่มีความยาวปานกลางถึงยาว เน้นการให้เหตุผลต่อเนื่องมากกว่าการเขียนเป็นข้อสั้น ไม่ใช้สรรพนามบุรุษที่หนึ่ง ไม่ใช้ภาษาพูด และไม่ใช้เครื่องหมายอัศเจรีย์

| องค์ประกอบ | แนวปฏิบัติของเล่ม | ตัวอย่างจากเล่ม |
|---|---|---|
| ผู้กระทำในประโยค | ใช้ "หลักสูตร" "คณะกรรมการพัฒนาหลักสูตร" หรือ "มหาวิทยาลัย" เป็นประธาน | "หลักสูตรได้บูรณาการกลยุทธ์การจัดการเรียนการสอน 5 รูปแบบหลัก" |
| คำเชื่อมเปิดย่อหน้า | "ในยุคแห่ง…" · "เพื่อตอบสนองต่อ…" · "จากการวิเคราะห์…" · "ด้วยเหตุนี้…" · "ยิ่งไปกว่านั้น…" · "ทั้งนี้…" | "ด้วยเหตุนี้ บทบาทที่สำคัญที่สุดของวิศวกรปัญญาประดิษฐ์ในอนาคตจึงมิใช่…" |
| คำลงท้ายหัวข้อนำ | "ดังมีรายละเอียดต่อไปนี้" · "ประกอบด้วย" · "ดังนี้" | "อันเป็นตัวกำหนดสมรรถนะที่บัณฑิตยุคใหม่ต้องมี ดังมีรายละเอียดต่อไปนี้" |
| คำปฏิเสธเชิงวิชาการ | ใช้ "มิใช่" แทน "ไม่ใช่" ในประโยคเชิงนิยาม | "จึงมิใช่การเป็นเพียงโปรแกรมเมอร์" |
| คำแสดงความจำเป็น | "พึงมี" · "ต้องมี" · "จำเป็นต้อง" | "มาตรฐานทางวิชาชีพที่บัณฑิตทุกคนพึงมี" |

## 2. การใช้ศัพท์ภาษาอังกฤษ

**หลักการ:** เขียนศัพท์ภาษาไทยเป็นตัวหลัก แล้ววงเล็บภาษาอังกฤษกำกับ**เฉพาะครั้งแรก**ที่ปรากฏในแต่ละหมวด หลังจากนั้นใช้ภาษาไทยล้วน

- ✅ "การเปลี่ยนผ่านทางเทคโนโลยีอย่างพลิกผัน (Technological Disruption)"
- ✅ "การจัดการศึกษาที่มุ่งเน้นผลลัพธ์ (Outcome-Based Education: OBE)" — ใช้เครื่องหมายทวิภาคเมื่อมีตัวย่อ
- ✅ "สำนักงานส่งเสริมเศรษฐกิจดิจิทัล (depa)" — ชื่อหน่วยงานไทยขึ้นก่อน ตัวย่อสากลในวงเล็บ
- ❌ ไม่เขียนภาษาอังกฤษเดี่ยวโดยไม่มีคำไทยนำ ยกเว้นชื่อเฉพาะทางเทคนิคที่ไม่มีศัพท์บัญญัติ เช่น Python, PLC/SCADA, MLOps

**ศัพท์บัญญัติที่เล่มนี้ใช้เป็นมาตรฐาน**

| ภาษาอังกฤษ | คำไทยที่เล่มใช้ |
|---|---|
| Artificial Intelligence | ปัญญาประดิษฐ์ |
| Machine Learning | การเรียนรู้ของเครื่อง |
| Deep Learning | การเรียนรู้เชิงลึก |
| Internet of Things | อินเทอร์เน็ตของสรรพสิ่ง |
| Edge Computing | การประมวลผลที่ขอบเครือข่าย |
| Computer Vision | คอมพิวเตอร์วิทัศน์ |
| Generative AI | ปัญญาประดิษฐ์เชิงสร้าง / เชิงรู้สร้าง |
| Agentic AI | ระบบเอเจนต์ปัญญาประดิษฐ์ |
| Digital Twin | ดิจิทัลทวิน / ฝาแฝดดิจิทัล |
| Stakeholders | ผู้มีส่วนได้ส่วนเสีย |
| Graduate Attributes | ลักษณะบัณฑิต |

## 3. ระบบเลขหัวข้อ

เล่มใช้เลขอารบิกสามระดับสำหรับหัวข้อ และวงเล็บปิดสำหรับรายการย่อยภายในเนื้อความ

```
หมวดที่ 2                    ← ระดับหมวด (ขึ้นหน้าใหม่)
2.1 …                        ← ระดับหัวข้อหลัก
2.1.3 …                      ← ระดับหัวข้อย่อย
   1) …                      ← รายการในเนื้อความ
      1.1) …                 ← รายการย่อย
         2.1) …              ← รายการย่อยของข้อ 2
```

> [!warning] ข้อบกพร่องที่พบในเล่มปัจจุบัน
> หมวดที่ 2 เริ่มต้นที่ 2.1.2 โดยไม่มี 2.1.1 และมีหัวข้อ 2.2.2 ปรากฏซ้ำสองครั้ง การแก้ไขต้องไล่เลขให้ต่อเนื่องทั้งหมวดเสมอ

## 4. การอ้างหลักฐานและตัวเลข

เล่มนี้ให้น้ำหนักกับหลักฐานเชิงประจักษ์สูงมาก โดยเฉพาะหัวข้อความต้องการของตลาดแรงงาน รูปแบบการอ้างที่ใช้คือ **ระบุแหล่ง → ระบุปี → ระบุตัวเลข → ตีความ**

> "ข้อมูลจากสภาเศรษฐกิจโลก (World Economic Forum) และสำนักงานส่งเสริมเศรษฐกิจดิจิทัล (depa) ชี้ชัดว่า…"

**แนวปฏิบัติ**

1. เขียนตัวเลขด้วยเลขอารบิกและใส่เครื่องหมายจุลภาคคั่นหลักพัน เช่น 75,000 อัตรา
2. ใช้ "ร้อยละ" นำหน้าตัวเลขเสมอ ไม่ใช้เครื่องหมาย % ในเนื้อความ
3. ระบุปีพุทธศักราชเป็นหลัก และวงเล็บช่วงปีเมื่ออ้างการคาดการณ์ เช่น (พ.ศ. 2568–2572)
4. ทุกตัวเลขต้องระบุแหล่งอ้างอิงในประโยคเดียวกันหรือในตารางแนบ
5. ตัวเลขเดียวกันต้องตรงกันทุกหมวดของเล่ม หากปรับที่ใดต้องไล่แก้ทั้งเล่ม

## 5. รูปแบบตาราง

- คำบรรยายตารางอยู่**เหนือ**ตาราง ใช้รูปแบบ `ตารางที่ ⟨หมวด⟩.⟨ลำดับ⟩ ⟨ชื่อตาราง⟩`
- ชื่อตารางเป็นภาษาไทย และวงเล็บภาษาอังกฤษกำกับเมื่อเป็นชื่อเฉพาะของกรอบแนวคิด
- หัวคอลัมน์ใช้คำนามวลีสั้น ไม่ใส่เครื่องหมายวรรคตอนท้าย
- ตารางที่ใช้อ้างอิงย้อนกลับได้ ควรมีคอลัมน์**รหัส**เป็นคอลัมน์แรกเสมอ (เช่น SH, N, GA, PLO) เพื่อรองรับการตรวจประเมินตามเกณฑ์ AUN-QA

## 6. หลักการสอบย้อนกลับ (Traceability)

จุดแข็งของเล่มคือการออกแบบตามแนวทาง OBE ที่สอบย้อนกลับได้ครบวงจร ทุกหมวดจึงต้องแสดงรหัสกำกับให้เห็นห่วงโซ่นี้อย่างชัดเจน มิใช่เก็บไว้เฉพาะในภาคผนวก

```
ผู้มีส่วนได้ส่วนเสีย (SH1–SH8)
        ↓
ความต้องการจำเป็น (N1–N18)
        ↓
ลักษณะบัณฑิต (GA1–GA5)
        ↓
ผลลัพธ์การเรียนรู้ระดับหลักสูตร (PLO1–PLO7)
        ↓
ผลลัพธ์การเรียนรู้รายชั้นปี (YLO1.1–YLO4.4)
        ↓
ผลลัพธ์การเรียนรู้รายวิชา (CLO) และชุดทักษะ (EN-AISK01–09)
```
