# ขั้นที่ 15 · กลยุทธ์การสอน การประเมิน และกลยุทธ์ราย KSA

> **เป้าหมาย: ตอบคำถามสุดท้ายว่า "แล้วสอนยังไง วัดยังไง" ให้ครบทุกรหัส — และปิดหนี้ที่ค้างมาตั้งแต่ขั้นที่ 8**

## หลังจบขั้นนี้ต้องได้อะไร

| เมนู | เส้นทาง | เนื้อหา |
|---|---|---|
| การเรียนการสอน → กลยุทธ์การสอน | `/teaching` | 5 รูปแบบ และ PLO ที่แต่ละรูปแบบรับผิดชอบ |

| ข้อมูลอ้างอิง | `/refs` | มาตรฐานและบรรณานุกรม |

## Prompt A · สร้างข้อมูลในวอลต์

```text
เขียน 3 ไฟล์

1. 08_TQF2_Book_Revisions/09_Section5_Revised.md (หมวด 5 การจัดการเรียนการสอน)
   ตารางที่ 5.1 กลยุทธ์การสอน
     รหัสกลยุทธ์ | ชื่อกลยุทธ์ | คำอธิบายวิธีดำเนินการ | PLO ที่รับผิดชอบ | ระดับสูงสุดที่พาไปถึง
   ควรมี 4–6 รูปแบบ เช่น การเรียนรู้จากโครงงาน · ปฏิบัติการ · กรณีศึกษาจากอุตสาหกรรม ·
   การเรียนรู้ร่วมการทำงาน · สัมมนาและการนำเสนอ
   ทุก PLO ต้องมีกลยุทธ์อย่างน้อยหนึ่งรูปแบบที่พาไปถึงระดับ M

2. 08_TQF2_Book_Revisions/12_Section6_Revised.md (หมวด 6 การวัดและประเมินผล)
   หัวข้อ 6.1 การประเมินราย PLO
     PLO | วิธีประเมิน | หลักฐาน | จุดประเมิน (ชั้นปี/รายวิชา) | ผู้ประเมิน | เกณฑ์ผ่าน
   "ผู้ประเมิน" ต้องระบุว่าเป็นอาจารย์ผู้สอน กรรมการหลักสูตร หรือผู้ประเมินภายนอก
   PLO ที่ประเมินโดยอาจารย์ผู้สอนคนเดียวทั้งหมด ถือว่ามีความเสี่ยงเชิงความเที่ยงตรง
   ให้ระบุมาตรการเสริม เช่น การทวนสอบโดยกรรมการ

3. 03_OBE_PLO_Design_2570/06_OBE_References.md
   เอกสารอ้างอิงแยกตามประเภท: มาตรฐานสากล | เกณฑ์ประกันคุณภาพ | นโยบายชาติ |
   หลักสูตรคู่เทียบ | รายงานตลาดแรงงาน
   ทุกรายการต้องมีปีและลิงก์หรือเลขเอกสาร
```

## Prompt B · สร้างสคริปต์และหน้าเว็บ

```text
สร้างสคริปต์ 2 ตัวต่อท้าย npm run build:ksa
ทุกสคริปต์ต้อง normalise line ending และ throw error เมื่อ parse ได้ 0 รายการ

1. scripts/build-plo-teaching.mjs
   - อ่าน 09_Section5_Revised.md ตัดเอาเฉพาะตารางที่ 5.1
     และ 12_Section6_Revised.md ตัดเอาเฉพาะหัวข้อ 6.1
   - เขียน src/teachingData.js
     และเอกสารรวมกลับเข้าวอลต์ที่
     08_TQF2_Book_Revisions/20_Teaching_and_Assessment_by_PLO.md
   - พิมพ์สรุป: จำนวนกลยุทธ์ · จำนวน PLO · จำนวนแถวการประเมิน

2. scripts/build-ksa-pedagogy.mjs
   - กำหนดวิธีสอนและวิธีประเมินรายรหัส KSA ทั้งหมด
     โดยอนุมานจากมิติของรหัส (K/S/A) และชุดทักษะที่รหัสนั้นสังกัด
     แล้วเปิดให้ปรับเฉพาะรายที่ต้องการในไฟล์ override
   - กำหนด "รายวิชาแกน" ของแต่ละรหัสไม่เกิน 2 วิชา
     เลือกจากรายวิชาที่อ้างรหัสนั้นใน CLO และเป็นเจ้าภาพหลัก
     ถ้าให้ทุกวิชารับผิดชอบ แปลว่าไม่มีใครรับผิดชอบ
   - เขียน src/ksaPedagogyData.js
     และ 05_TQF2_Academic_Drafts/20_KSA_Teaching_and_Assessment.md
   - พิมพ์ "มีแกนครบ ?/<จำนวนรหัสทั้งหมด>" และแจ้งรหัสที่ยังไม่มีวิชาแกน

สร้าง 4 หน้าเว็บ
  pages/Teaching.jsx     (/teaching)
    section overview  ความครอบคลุม PLO — เมทริกซ์กลยุทธ์ × PLO
    section detail    รายละเอียดรายกลยุทธ์
    section perplo    กลยุทธ์รายข้อ PLO
  pages/Assessment.jsx   (/assessment)
    section summary   ตารางสรุปทุก PLO
    section perplo    รายละเอียดรายข้อ พร้อมป้ายเตือนเมื่อผู้ประเมินมีคนเดียว
  pages/KsaPedagogy.jsx  (/ksa-pedagogy)
    section table     ตารางกลยุทธ์และการประเมินทุกรหัส แยกแท็บ K/S/A
    section anchors   รายวิชาแกนที่ถูกอ้างมากที่สุด พร้อมเตือนเมื่อวิชาเดียวเป็นแกนเกิน 8 รหัส
  pages/References.jsx   (/refs)  จาก src/refData.js

ปิดท้าย: เขียน README ของโปรเจกต์ที่สรุปลำดับคำสั่ง build ทั้งหมดและตารางว่า
ข้อมูลแต่ละชุดมาจากไฟล์ไหนในวอลต์
```

## เกณฑ์ตรวจรับ — ตรวจทั้งระบบ

- [ ] `มีแกนครบ ?/?` — ทุกรหัส KSA มีรายวิชาแกน
- [ ] ทุก PLO มีกลยุทธ์การสอนที่พาไปถึง M และมีแผนประเมินของตัวเอง
- [ ] ไม่มี PLO ที่ประเมินโดยอาจารย์คนเดียวโดยไม่มีมาตรการทวนสอบ
- [ ] ไฟล์ `99_Pending.md` ว่างเปล่าแล้ว — ไม่มีหนี้ค้าง
- [ ] ลบไฟล์ที่สร้างอัตโนมัติทั้งหมดแล้วรันคำสั่งเดียวข้างบน → ได้กลับมาเหมือนเดิมทุกไฟล์
