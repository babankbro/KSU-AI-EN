# ขั้นที่ 4 · ผลลัพธ์การเรียนรู้ระดับหลักสูตร PLO1–7

> **เป้าหมาย: แปลงคุณลักษณะบัณฑิตให้เป็นข้อความที่ประเมินได้จริง และผูกกับมาตรฐานสากลเพื่อไม่ต้องเถียงว่าทำไมต้องมีกี่ข้อ**

## หลังจบขั้นนี้ต้องได้อะไร

| เมนู | เส้นทาง | เนื้อหา |
|---|---|---|
| ผลลัพธ์การเรียนรู้ → PLO | `/plo` · `/plo/:id` | PLO 7 ข้อ · เทียบ ABET SO · การตรวจ SMART |
| ผลลัพธ์การเรียนรู้ → ขั้นตอน OBE | `/obe` ⑥ | PLO ในสายธาร |

## Prompt A · สร้างข้อมูลในวอลต์

```text
เขียน 03_OBE_PLO_Design_2570/04_PLOs_7_OBE.md
ให้เป็น "เอกสารมาตรฐานถ้อยคำ PLO ของทั้งวอลต์" เอกสารอื่นทุกฉบับต้องอ้างถ้อยคำจากที่นี่

1. ประโยคนำร่วมที่แสดงเหนือรายการเสมอ
   "เมื่อสำเร็จการศึกษา ผู้เรียนสามารถแสดงผลลัพธ์การเรียนรู้ระดับหลักสูตรได้ดังต่อไปนี้"

2. PLO1–PLO7 โดยแต่ละข้อ "ขึ้นต้นด้วยคำกริยาโดยตรง"
   ห้ามขึ้นต้นด้วย "มีความรู้เกี่ยวกับ" "ตระหนักถึง" "เข้าใจ" เพราะประเมินไม่ได้

3. ตารางรายละเอียด
   คอลัมน์: รหัส | ถ้อยคำเต็ม | ระดับ Bloom | เทียบ ABET SO ข้อใด | GA ที่มา | หลักฐานการประเมินที่ยอมรับได้

4. ตารางตรวจ SMART รายข้อ
   คอลัมน์: รหัส | Specific | Measurable | Achievable | Relevant | Time-bound | ข้อสังเกต
   ถ้าข้อใดไม่ผ่านเกณฑ์ใด ให้เขียนไว้ตรง ๆ พร้อมแนวทางแก้ อย่าติ๊กผ่านทั้งหมด

5. ตารางสอบย้อนกลับ GA ↔ PLO
   คอลัมน์: GA | PLO ที่แปลงออกมา | เหตุผล

ข้อบังคับ
- ทุก GA จากขั้นที่ 3 ต้องมี PLO อย่างน้อยหนึ่งข้อรองรับ
- จำนวน PLO ให้อิงมาตรฐานที่เลือก (เช่น ABET EAC มี SO 7 ข้อ) ไม่ใช่ตั้งเลขเอง
  แล้วระบุในเอกสารว่าอิงมาตรฐานใด ฉบับปีใด
- ถ้ามี PLO ชุดเก่าอยู่แล้ว ให้เก็บไว้เป็นเอกสารประวัติในไฟล์แยก
  และเขียนกำกับให้ชัดว่าชุดไหนคือถ้อยคำที่ใช้จริง

เขียนไฟล์ 03_OBE_PLO_Design_2570/05_Mapping_Tables.md
ตารางเชื่อม Needs ↔ GA ↔ PLO ทั้งสายให้สอบย้อนกลับได้ครบทุกข้อ
ปิดท้ายด้วยรายการความต้องการที่ยังไม่มี PLO ใดตอบ
```

> [!important] ยังไม่ต้องเขียนว่ารายวิชาไหนรับผิดชอบ PLO ใด
> ตาราง `07_Curriculum_PLO_Mapping.md` ต้องรอจนกว่าจะมีรายวิชาในขั้นที่ 10
> **ให้สร้างไฟล์เปล่าไว้พร้อมป้าย `[!todo] รอรายวิชาจากขั้นที่ 10`** แล้วบันทึกไว้ใน `99_Pending.md`

## Prompt B · สร้างหน้า PLO

```text
1. เพิ่มใน src/data.js
   PLO_NAME   { 1..7: "ชื่อสั้นสำหรับป้าย" }
   PLO_DETAIL { 1..7: { full, bloom, abet, ga: [], evidence, smart } }
   PLO_COLOR  { 1..7: สีประจำข้อ }  ใช้ร่วมกันทั้งเว็บตั้งแต่นี้ไป
   PLO_LEAD   ประโยคนำร่วม

2. หน้า src/pages/Plos.jsx (/plo)
   - แสดง PLO_LEAD เป็นแถบเด่นเหนือรายการเสมอ
   - การ์ด PLO1–7 ระบายสีตาม PLO_COLOR คลิกเข้าหน้ารายละเอียด
   - ตารางเทียบ ABET SO
   - ตารางตรวจ SMART พร้อมไอคอนผ่าน/ไม่ผ่านรายเกณฑ์
   - ส่วน "รายวิชาที่รับผิดชอบ" ให้ใส่ placeholder ที่แสดงป้าย
     "รอเชื่อมรายวิชา — ขั้นที่ 14" ไม่ใช่ปล่อยว่าง

3. หน้า src/pages/PloDetail.jsx (/plo/:id)
   ถ้อยคำเต็ม · ระดับ Bloom · GA ที่มา (คลิกกลับไป /obe#ga ได้) ·
   หลักฐานการประเมิน · ผลการตรวจ SMART
   ถ้า id ไม่อยู่ใน 1–7 ให้ไปหน้า NotFound

4. เพิ่มส่วน ⑥ id="plo" ในหน้า /obe ต่อจาก GA
   และเติมป้าย PLO ในการ์ด GA ที่เว้นไว้ในขั้นที่ 3

5. เพิ่ม PLO1–7 เข้าทะเบียน codeInfo.js
   ให้ป้าย PLO ทุกจุดในเว็บคลิกได้และชี้ค้างแล้วเห็นถ้อยคำเต็ม
```
