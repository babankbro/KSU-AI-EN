# ขั้นที่ 7 · ชุดทักษะ AISK01–09

> **เป้าหมาย: สร้างสะพานระหว่างภาษาของหลักสูตรกับภาษาของผู้ประกอบการ — เขาไม่ถามว่าเด็กผ่าน PLO3 หรือยัง เขาถามว่าเด็กทำ MLOps เป็นไหม**

## ชุดทักษะคือหน่วยที่จะพิมพ์ลง Skill Transcript

| | PLO | ชุดทักษะ AISK |
|---|---|---|
| ผู้อ่าน | ผู้ตรวจคุณภาพการศึกษา | ผู้ประกอบการ · นักศึกษา |
| ภาษา | ผลลัพธ์การเรียนรู้ | ชื่อความสามารถและเครื่องมือจริง |
| ระบุระดับ | I / R / M | L1–L4 รายทักษะย่อย |
| ใช้ทำอะไร | ทวนสอบหลักสูตร | ยื่นสมัครงาน |

## Prompt A · สร้างข้อมูลในวอลต์

```text
เขียน 05_TQF2_Academic_Drafts/11_Skill_Set_Matrix_and_KSA.md ส่วน B

ตารางที่ 1 — กลุ่มชุดทักษะ
คอลัมน์: รหัสกลุ่ม | ชื่อไทย | ชื่ออังกฤษ
ใช้รหัส G1–G7 จัดกลุ่มตามลักษณะงาน ไม่ใช่ตามชั้นปี

ตารางที่ 2 — ชุดทักษะ
คอลัมน์: รหัสชุด | กลุ่ม G | ประเภท (Hard/Soft) | ชื่อไทย | ชื่ออังกฤษ |
        ทักษะที่รวมอยู่ (HS/SS/EF) | PLO ที่รับผิดชอบ |
        บทบาทแขนง T1 | T2 | T3
ใช้รหัส EN-AISK01 ถึง EN-AISK09
บทบาทแขนงใช้สัญลักษณ์ ● ทักษะหลัก · ○ ทักษะสนับสนุน · – ไม่เกี่ยวข้อง

ตารางที่ 3 — ทักษะย่อยรายชุด
คอลัมน์: รหัสชุด | ชื่อทักษะย่อย | ระดับเป้าหมาย L1–L4 | เครื่องมือที่ใช้จริง
ชื่อเครื่องมือให้ระบุของจริงที่ใช้ในอุตสาหกรรม เช่น "PyTorch, TensorFlow"
ไม่ใช่ "ซอฟต์แวร์การเรียนรู้เชิงลึก"

ข้อบังคับ
- ทุกทักษะ HS/SS/EF จากขั้นที่ 6 ต้องอยู่ในชุดทักษะอย่างน้อยหนึ่งชุด
- ทักษะหนึ่งตัวอยู่ได้หลายชุด ถือเป็นเรื่องปกติ เช่น การเขียนโปรแกรม
- ทุกชุดต้องระบุ PLO ที่รับผิดชอบอย่างน้อยหนึ่งข้อ
- ทุกชุดต้องมีบทบาทครบทั้งสามแขนง จะเป็น – ก็ได้ แต่ต้องเขียน
- จำนวนชุดควรอยู่ที่ 7–10 ชุด เพราะเป็นจำนวนที่พิมพ์ลง transcript หนึ่งหน้าได้
- ยังไม่ต้องเขียนคอลัมน์รหัส KSA — จะเติมในขั้นที่ 8
- ยังไม่ต้องเขียนว่ารายวิชาใดรองรับชุดใด — จะเติมในขั้นที่ 14

ปิดท้ายด้วยรายการทักษะที่ยังไม่มีชุดใดรับ ถ้ามีต้องอธิบาย
```

## Prompt B · สร้างหน้าเว็บ

```text
1. เพิ่มใน src/obeData.js
   GROUPS     = { G1..G7: { name, en, color } }
   SKILL_SETS = [{ id, g, type, name, en, skills: [], plo: [],
                   track: { T1, T2, T3 }, sub: [{ n, lv, tools }],
                   ksa: [] }]    // ksa เว้นว่างไว้ เติมขั้นที่ 8

2. เพิ่มส่วน ⑤ id="set" ในหน้า src/pages/Obe.jsx
   - การ์ดหนึ่งใบต่อหนึ่งชุด ระบายสีตามกลุ่ม G1–G7
   - แต่ละการ์ดแสดง
       ป้ายทักษะที่รวมอยู่ คลิกแล้วเลื่อนไปที่ตารางทักษะในส่วน ④
       ป้าย PLO ที่รับผิดชอบ คลิกแล้วไป /plo/:id
       แถวบทบาทแขนง ● ○ – แสดงเป็นตาราง 3 ช่อง
       รายการทักษะย่อยพร้อมระดับ L1–L4 และชื่อเครื่องมือ
   - ตัวกรอง: ตามกลุ่ม G · ตามแขนงที่เป็นทักษะหลัก · ตามประเภท Hard/Soft

3. เพิ่มมุมมองเมทริกซ์
   แถว = ทักษะ HS/SS/EF · คอลัมน์ = ชุด AISK01–09 · ช่อง = ✓
   ใต้ตารางแสดงจำนวนชุดที่แต่ละทักษะปรากฏ
   ทักษะที่ปรากฏ 0 ชุด ให้ไฮไลต์แดง

4. เพิ่มรหัส AISK และ G เข้าทะเบียน codeInfo.js

5. แถบตรวจ
   - ทักษะที่ไม่มีชุดใดรับ
   - ชุดที่ไม่มี PLO รับผิดชอบ
   - ชุดที่ไม่มีทักษะย่อยเลย
```
