# คู่มือสร้างหลักสูตรและเว็บทีละขั้น — ชุดคู่ Prompt

> สอนวิธีสร้างระบบนี้ใหม่ตั้งแต่ **วอลต์เปล่าที่มีแต่ชื่อไฟล์** จนถึงเว็บครบทุกเมนู
> ทุกขั้นมี **Prompt คู่กัน 2 ตัว** — ตัวหนึ่งสร้างข้อมูลในวอลต์ อีกตัวสร้างหน้าเว็บที่กินข้อมูลนั้น

## ลำดับการสอน — ผลลัพธ์มาก่อนโครงสร้าง

ชุดนี้เรียงตามลำดับ **Outcome-Based Education จริง** ไม่ใช่ตามลำดับที่เล่ม มคอ.2 พิมพ์ออกมา

```mermaid
flowchart LR
    A["ขั้น 2–4<br/>ใครต้องการอะไร<br/>Need → GA → PLO"] --> B["ขั้น 5–8<br/>ตลาดต้องการทักษะอะไร<br/>Job → Skill → AISK → KSA"]
    B --> C["ขั้น 9–12<br/>ออกแบบโครงสร้างมารองรับ<br/>หมวด → รายวิชา → ลำดับ → แผน"]
    C --> D["ขั้น 13–15<br/>ผูกกลับให้ครบวง<br/>YLO → CLO → การสอนและประเมิน"]
```

> [!important] ทำไมต้องเรียงแบบนี้
> ถ้าเริ่มจากโครงสร้างหลักสูตรก่อน จะได้ **หลักสูตรที่หาเหตุผลย้อนหลัง** — มีรายวิชาอยู่แล้วค่อยเขียน PLO ให้เข้ากับวิชาที่มี
> การเริ่มจากความต้องการและหลักฐานตลาด บังคับให้ตอบได้ว่า *ทำไมต้องมีวิชานี้* ก่อนที่จะเขียนวิชานั้นลงไป
> และเมื่อถึงขั้นออกแบบโครงสร้าง จะมีเกณฑ์ตัดสินอยู่แล้วว่าวิชาไหนควรอยู่หรือควรตัด

## หลักการของคู่มือนี้

> [!important] กฎเหล็ก 3 ข้อ
> 1. **วอลต์มาก่อนเว็บเสมอ** — ห้ามพิมพ์ข้อมูลหลักสูตรลงในไฟล์ `.js` โดยตรง
> 2. **หนึ่งขั้น = หนึ่งเมนูที่ใช้งานได้จริง** — จบขั้นแล้วต้องเปิดหน้านั้นดูได้
> 3. **ไม่ข้ามขั้น** — ขั้นหลังอ้างรหัสที่ขั้นก่อนสร้างไว้

## วิธีใช้ Prompt ในคู่มือนี้

- **ระบุ path เต็มเสมอ** ทั้งไฟล์ต้นทางและปลายทาง
- **บอกรูปแบบตารางให้ชัด** ว่าคอลัมน์ที่เท่าไรเก็บอะไร เพราะสคริปต์รุ่นหลัง parse ด้วยตำแหน่งคอลัมน์
- **สั่งให้พิมพ์สรุปจำนวนที่สร้างได้** ทุกครั้ง เพื่อจับกรณี parse ไม่เข้า
- **ห้ามให้แก้ไฟล์ที่สร้างอัตโนมัติ** ระบุตรง ๆ ว่า "แก้ที่เอกสารในวอลต์เท่านั้น"

> [!warning] บทเรียนจากของจริง
> ระบบนี้เคยพังเงียบ ๆ เพราะสคริปต์ใช้ `split("\n")` กับไฟล์ที่บันทึกเป็น CRLF บนวินโดวส์ แล้ว regex ที่ปิดท้ายด้วย `$` ไม่ match — ผลคือเขียนทับไฟล์ผลลัพธ์ด้วยข้อมูลว่างโดยไม่มีข้อความเตือน
> **ทุก Prompt B จึงมีบรรทัดบังคับให้ normalise line ending และให้ throw error เมื่อ parse ได้ 0 รายการ**
