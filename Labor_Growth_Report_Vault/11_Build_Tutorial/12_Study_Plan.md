## Prompt A · สร้างข้อมูลในวอลต์

```text
เขียนส่วนแผนการเรียนใน
04_Course_Descriptions_2570/11_Year_Level_Course_Sequence_and_YLO.md
(ส่วน YLO จะเติมในขั้นที่ 13)

1. ตารางแผนการเรียนรายภาค 8 ตาราง
   คอลัมน์: รหัสวิชา | ชื่อวิชา | หน่วยกิต | กลุ่มวิชา | เฉพาะแผน (ก/ข/ทั้งสอง)
   ปิดท้ายทุกตารางด้วยผลรวมหน่วยกิตของภาคนั้น

2. ตารางสรุปการกระจายหน่วยกิต
   คอลัมน์: ภาคการศึกษา | หน่วยกิตแผน ก | หน่วยกิตแผน ข | ธีมของภาค (ไทย/อังกฤษ)
   ธีมของภาคควรสะท้อนความสามารถที่ผู้เรียนจะได้ในภาคนั้น ไม่ใช่แค่ชื่อกลุ่มวิชา

3. หัวข้อ "สองแผนการเรียน"
   - แผน ก แผนปกติ · แผน ข บูรณาการกับสถานประกอบการ (CWIE)
   - ต่างกันเฉพาะภาคใด และเหมือนกันทุกภาคที่เหลือ
   - เลือกแผนตอนไหน และเปลี่ยนแผนได้หรือไม่โดยไม่เสียหน่วยกิต

4. หัวข้อ "เหตุผลของการจัดลำดับ"
   อธิบายจุดออกแบบที่ตั้งใจ เช่น ทำไมวิชาเตรียมสหกิจจึงอยู่ก่อนภาคสุดท้าย

ข้อบังคับ
- ผลรวมหน่วยกิต 8 ภาคของแต่ละแผน = หน่วยกิตรวมของหลักสูตร
- ห้ามวางรายวิชาที่มีวิชาบังคับก่อน (hard) ไว้ภาคเดียวกันหรือก่อนวิชานั้น
- หน่วยกิตต่อภาคไม่ควรเกิน 22 และไม่ควรต่ำกว่า 12 ยกเว้นภาคสหกิจ
```

## Prompt B · สร้างหน้าแผนการเรียน

```text
1. เพิ่มใน src/data.js
   PLANS       = { A: { key, name, sub, extra7: [] }, B: { ... } }
   SEM_TITLE   = { [ภาค]: { th, en } }
   SEM_TOTALS  คำนวณจาก COURSES ห้าม hardcode
   YEAR_CREDITS · YEAR_COLOR
   coursesOfPlan(plan) = COURSES.filter(c => !c.plan || c.plan === plan)
   รายวิชาที่มีเฉพาะแผนใดแผนหนึ่งให้ใส่ฟิลด์ plan: "A" หรือ "B"

2. สร้าง src/PlanBoard.jsx เวอร์ชันพื้นฐาน
   - กระดาน 8 คอลัมน์ หนึ่งคอลัมน์ต่อหนึ่งภาค จัดกลุ่มเป็น 4 ปี
   - หัวคอลัมน์: เลขภาค · ธีมของภาค · ผลรวมหน่วยกิตที่คำนวณสด
   - การ์ดรายวิชาระบายสีตามกลุ่มวิชา พร้อมคำอธิบายสัญลักษณ์
   - แถบสรุป: หน่วยกิตรวมของแผนที่เลือก เทียบกับ TOTAL_CREDITS
     ถ้าไม่ตรงให้ขึ้นแถบเตือนพร้อมบอกส่วนต่าง
   - ปุ่มสลับแผน ก / แผน ข วิชาที่ต่างกันต้องมีป้ายกำกับ
   - คลิกการ์ดไป /courses/:code
   - ทุก grid container ต้องใช้ minmax(0,1fr) ไม่ใช่ auto

3. หน้า src/pages/Plan.jsx เรียก <PlanBoard plan={plan}/> พร้อมคำอธิบายสองแผน

4. สร้าง scripts/build-study-plan-md.mjs   (npm run build:plan)
   สร้างตารางแผนการเรียนกลับเข้าวอลต์ที่
   08_TQF2_Book_Revisions/14_Section4_4_Study_Plan.md เพื่อวางในเล่ม มคอ.2
   สคริปต์นี้อ่านจาก data.js เพราะเป็นการสร้างเอกสารจากข้อมูลที่ผ่านการตรวจลำดับแล้ว
```

> [!important] ขั้นนี้เป็นครั้งแรกที่ข้อมูลไหลกลับเข้าวอลต์
> ตารางแผนการเรียนในเล่ม มคอ.2 **ไม่ควรพิมพ์ด้วยมือ** เพราะจะหลุดจากข้อมูลจริงทันทีที่ย้ายวิชา
