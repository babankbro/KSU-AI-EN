# ขั้นที่ 9 · โครงสร้างหลักสูตร หน่วยกิต และอาจารย์

> **เป้าหมาย: ออกแบบโครงสร้างมารองรับผลลัพธ์ที่กำหนดไว้แล้วในขั้นที่ 2–8 — ไม่ใช่ตั้งโครงสร้างก่อนแล้วหาเหตุผลย้อนหลัง**

## จุดต่างของขั้นนี้ในลำดับ Outcome-First

เมื่อมาถึงขั้นนี้ เรามีอยู่ในมือแล้ว

- ความต้องการ 18 ข้อ และ PLO 7 ข้อ ที่ต้องพาไปให้ถึง
- ทักษะเป้าหมาย 36 ตัวที่มีหลักฐานตลาดรองรับ
- ชุดทักษะ 9 ชุดและรหัส KSA 54 รหัสที่ต้องมีคนสอน

**โครงสร้างหลักสูตรจึงไม่ใช่การเดา** แต่เป็นการตอบคำถามว่า *ต้องมีกี่หน่วยกิตและกลุ่มวิชาแบบไหนจึงจะพาไปถึงสิ่งเหล่านั้นได้*

## หลังจบขั้นนี้ต้องได้อะไร

| เมนู | เส้นทาง | เนื้อหา |
|---|---|---|
| หน้าแรก | `/` | ตัวเลขสำคัญ · สัดส่วนหน่วยกิต · การ์ดนำทาง |
| หลักสูตร → โครงสร้างหลักสูตร | `/structure` · `/structure/:id` | 3 หมวด · 8 กลุ่มวิชา · กลุ่มย่อย |
| หลักสูตร → อาจารย์ประจำหลักสูตร | `/faculty` | อาจารย์และคุณวุฒิ |

## Prompt B · สร้างหน้าเว็บ

```text
1. เพิ่มใน src/data.js พร้อมคอมเมนต์ว่าซิงก์มาจากไฟล์ไหนในวอลต์
   TOTAL_CREDITS
   STRUCTURE_TOP = [{ name, credits, ids: [รหัสกลุ่ม] }]
   STRUCTURE     = [{ id, no, name, code, credits, n, g, note, sub? }]
   SUBGROUPS     = { [รหัสกลุ่ม]: { note, items: [{ name, sub, codes: [] }] } }
   GROUP_NAME · GROUP_COLOR · TRACK_NAME
   หมายเหตุ: ช่อง codes ของ SUBGROUPS จะว่างไว้ก่อน เติมในขั้นที่ 10

2. สร้าง src/facultyData.js
   FACULTY = [{ order, rank, name, role, field, degrees: [{ level, abbr, major, inst, year }] }]

3. หน้า src/pages/Home.jsx
   - แถบตัวเลขสำคัญ: หน่วยกิตรวม · จำนวนปี · จำนวนแขนง · จำนวน PLO · จำนวนชุดทักษะ
   - แถบสัดส่วนหน่วยกิตแบบ stacked bar จาก STRUCTURE_TOP คำนวณ % จากข้อมูล ห้าม hardcode
   - การ์ดนำทาง อ่านชื่อและคำอธิบายจาก navConfig.js ไม่เขียนซ้ำ

4. หน้า src/pages/Structure.jsx
   - การ์ดหนึ่งใบต่อหนึ่งกลุ่มวิชา แสดงเลขที่กลุ่ม ชื่อ คำนำหน้ารหัส หน่วยกิต จำนวนวิชา
   - ในการ์ดมีรายการกลุ่มย่อย แต่ละแถวคลิกเข้า /structure/:id
   - แสดงป้ายชุดทักษะ AISK ที่กลุ่มนั้นรับผิดชอบ คลิกแล้วไป /obe#set
     นี่คือส่วนที่ทำให้เห็นว่าโครงสร้างมาจากผลลัพธ์ ไม่ใช่มาลอย ๆ
   - แถวกลุ่มย่อยจัดด้วย CSS grid และต้องใช้ grid-template-columns: minmax(0,1fr)
     ไม่ใช่ค่า auto เพราะคอลัมน์ auto จะกว้างตามแถวที่ยาวที่สุดจนทะลุขอบการ์ด
   - ตรวจว่าผลรวมหน่วยกิตทุกกลุ่ม = TOTAL_CREDITS ถ้าไม่ตรงให้ขึ้นแถบเตือนสีแดง

5. หน้า src/pages/StructureGroup.jsx (/structure/:id)
   ตารางกลุ่มย่อย พร้อม anchor ลิงก์ตรงถึงกลุ่มย่อยได้
   ส่วนรายวิชาให้แสดงป้าย "รอรายวิชา — ขั้นที่ 10"

6. หน้า src/pages/Faculty.jsx
   อาจารย์และคุณวุฒิครบทุกระดับ · ตารางความพร้อมด้านผู้สอนต่อชุดทักษะ
```
