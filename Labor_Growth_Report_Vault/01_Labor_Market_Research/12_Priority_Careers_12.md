# 12 อาชีพเป้าหมายสำคัญของหลักสูตร

> คัดเลือก Track ละ 3 อาชีพ และอาชีพภาพรวมหลักสูตร 3 อาชีพ
> ปรับปรุงข้อมูล ณ 21 กรกฎาคม 2569 / 2026-07-21

## หลักเกณฑ์การคัดเลือก

อาชีพทั้ง 12 รายการคัดจาก [[11_Career_Paths_by_Track|บัญชีเส้นทางอาชีพฉบับเต็ม]] โดยพิจารณาร่วมกัน 3 มิติ

1. **Market Reality:** พบตำแหน่งหรือชื่อตำแหน่งใกล้เคียงในตลาดแรงงานจริง
2. **Track Relevance:** เชื่อมตรงกับอุตสาหกรรม รายวิชา และ Portfolio ของ Track
3. **Future Potential:** รองรับ AI, data, robotics, sensor networks, cloud และเทคโนโลยีอุบัติใหม่

สัญลักษณ์สถานะตลาด:

- **M — Market Core:** ตำแหน่งหลักที่พบในตลาดกว้าง
- **S — Sector Critical:** สำคัญในอุตสาหกรรมเฉพาะ แม้จำนวนประกาศอาจไม่มากเท่างานดิจิทัลทั่วไป
- **F — Future/Emerging:** งานอนาคตหรือบทบาทที่กำลังเติบโต ต้องมี Portfolio เฉพาะทาง

## Track 1 — เกษตรอัจฉริยะ

### T1-1 วิศวกรเกษตรอัจฉริยะและไอโอที

**Smart Agriculture and IoT Engineer — Sector Critical**

- **เหตุผลที่เลือก:** เป็นบทบาทหลักในการนำ sensor, communication, edge/cloud และระบบควบคุมไปใช้จริงในฟาร์ม โรงเรือน และระบบชลประทาน ชื่อตำแหน่งในตลาดอาจใช้ Smart Farm Engineer, IoT Engineer, Application Engineer หรือ Precision Agriculture Engineer
- **งานหลัก:** สำรวจหน้างาน ออกแบบระบบ sensor/gateway ควบคุมน้ำหรือสภาพแวดล้อม เชื่อม Dashboard และทดสอบความเสถียร
- **รายวิชาหลัก:** EN-001-0X7, EN-131-104, EN-132-103, วิชาเกษตรกรรมอัจฉริยะและชลประทาน, วิชา ML และข้อมูลเซนเซอร์ในฟาร์ม
- **Portfolio ขั้นต่ำ:** ระบบฟาร์ม IoT ที่วัด–ควบคุม–แจ้งเตือนได้ พร้อม architecture, cost และผลทดสอบภาคสนาม
- **คำค้นงาน:** `Smart Farm Engineer`, `Agricultural IoT`, `IoT Engineer`, `Precision Agriculture`, `Application Engineer Agriculture`

### T1-2 นักวิเคราะห์ข้อมูลเกษตรและเกษตรแม่นยำ

**Agricultural Data and Precision Farming Analyst — Sector/Market**

- **เหตุผลที่เลือก:** Data Scientist/Data Analyst เป็นกลุ่มงาน AI ที่มีจำนวนประกาศสูงที่สุดในข้อมูล TDRI ขณะที่ภาคเกษตรต้องการการพยากรณ์ผลผลิต การจัดการน้ำ/ปุ๋ย และการตัดสินใจจากข้อมูล
- **งานหลัก:** รวมและทำความสะอาดข้อมูลฟาร์ม วิเคราะห์เชิงพื้นที่/อนุกรมเวลา สร้าง Dashboard และแบบจำลองพยากรณ์
- **รายวิชาหลัก:** EN-001-0X2, EN-131-106, EN-131-107, EN-132-103, วิชาพยากรณ์ข้อมูลฟาร์ม และ GIS
- **Portfolio ขั้นต่ำ:** ชุดข้อมูลจริงหรือข้อมูลเปิด + data pipeline + forecast/dashboard + ข้อเสนอการตัดสินใจสำหรับเกษตรกร
- **คำค้นงาน:** `Agricultural Data Analyst`, `Farm Data Analyst`, `Precision Agriculture Analyst`, `GIS Analyst`, `Data Analyst Agriculture`

### T1-3 วิศวกร AI และคอมพิวเตอร์วิทัศน์ด้านเกษตร

**Agricultural AI and Computer Vision Engineer — Future**

- **เหตุผลที่เลือก:** เป็นงานอนาคตที่เชื่อม AI กับการตรวจโรคพืช นับผลผลิต คัดเกรด และภาพ UAV; อาจประกาศภายใต้ชื่อ Computer Vision Engineer หรือ AI Engineer โดยระบุโดเมนเกษตร/อาหาร
- **งานหลัก:** สร้าง dataset ภาพ พัฒนา detection/classification/segmentation นำโมเดลลง edge และประเมินความแม่นยำในสภาพแวดล้อมจริง
- **รายวิชาหลัก:** EN-131-103, EN-131-106, EN-132-104 และวิชา Computer Vision สำหรับการคัดเกรดเกษตร
- **Portfolio ขั้นต่ำ:** ระบบตรวจโรคหรือคัดเกรดที่มี data sheet, baseline, error analysis, latency และ demo บนอุปกรณ์จริง
- **คำค้นงาน:** `Computer Vision Engineer`, `AI Engineer Agriculture`, `Machine Vision Agriculture`, `Vision AI`, `UAV Image Analysis`

## Track 2 — ปัญญาประดิษฐ์ภาคอุตสาหกรรม

### T2-1 วิศวกรระบบควบคุมและอัตโนมัติ

**Automation and Control Engineer — Market/Sector Core**

- **เหตุผลที่เลือก:** เป็นตำแหน่งจริงที่ใช้กว้างในโรงงานและ System Integrator และเป็นฐานก่อนต่อยอดสู่ Industrial AI; ตลาดไทยใช้ชื่อ Automation Engineer, Control Engineer หรือ PLC Engineer
- **งานหลัก:** โปรแกรม PLC/HMI/SCADA เชื่อม I/O และ industrial network ทดสอบ interlock, alarm และ safety
- **รายวิชาหลัก:** EN-001-0X7, EN-001-0X10, EN-132-106 และวิชาเครื่องมือวัดและควบคุมกระบวนการ
- **Portfolio ขั้นต่ำ:** สถานีควบคุมจำลองหรือชุดทดลอง PLC/SCADA พร้อม wiring, sequence, HMI และ test cases
- **คำค้นงาน:** `Automation Engineer`, `Control Engineer`, `PLC Engineer`, `SCADA Engineer`, `Instrumentation and Control`

### T2-2 วิศวกรหุ่นยนต์และบูรณาการระบบ

**Robotics and System Integration Engineer — Market/Sector Core**

- **เหตุผลที่เลือก:** TDRI พบงาน Robotics and Automation เพิ่ม 44.2% ต่อปี และ สอวช. ประเมินความต้องการกำลังคน Smart Electronics and Industrial Robotics สูงถึง 226,423 ตำแหน่งในช่วง 2568–2572
- **งานหลัก:** โปรแกรม robot/drive เชื่อม vision, PLC, conveyor, safety และ commissioning ระบบกับหน้างานจริง
- **รายวิชาหลัก:** EN-132-106, วิชาหุ่นยนต์อุตสาหกรรม ระบบขนถ่ายวัสดุ และคลังสินค้าอัตโนมัติ
- **Portfolio ขั้นต่ำ:** robotic cell หรือ simulation ที่มี sequence, vision/control integration, cycle time และ risk assessment
- **คำค้นงาน:** `Robotics Engineer`, `System Integration Engineer`, `Robot Programmer`, `Automation System Integrator`, `Mechatronics Engineer`

### T2-3 วิศวกร AI อุตสาหกรรมและบำรุงรักษาเชิงพยากรณ์

**Industrial AI and Predictive Maintenance Engineer — Future**

- **เหตุผลที่เลือก:** เป็นบทบาทอนาคตที่เชื่อม ML กับข้อมูล vibration, current, temperature และ process data เพื่อลด downtime; ในตลาดอาจใช้ชื่อ Reliability Engineer, Condition Monitoring Engineer หรือ Data Scientist–Manufacturing
- **งานหลัก:** วางระบบเก็บข้อมูลเครื่องจักร สร้าง anomaly/failure model เชื่อม maintenance workflow และประเมินผลด้าน downtime/cost
- **รายวิชาหลัก:** EN-131-106, EN-131-107, EN-132-105 และวิชาการบำรุงรักษาเชิงพยากรณ์ด้วย AI
- **Portfolio ขั้นต่ำ:** predictive-maintenance pipeline ที่มี signal processing, model evaluation, alert และ maintenance recommendation
- **คำค้นงาน:** `Predictive Maintenance Engineer`, `Reliability Engineer`, `Condition Monitoring`, `Industrial AI Engineer`, `Manufacturing Data Scientist`

## Track 3 — นวัตกรรมและซอฟต์แวร์ AI

### T3-1 วิศวกรปัญญาประดิษฐ์และการเรียนรู้ของเครื่อง

**AI/ML Engineer — Market and Future Core**

- **เหตุผลที่เลือก:** TDRI พบประกาศ AI/ML Engineer เพิ่มจาก 85 เป็น 321 ตำแหน่งต่อไตรมาส หรือ 277.6% ต่อปี แม้ฐานยังเล็ก จึงเป็นทั้งงานที่มีจริงและงานเติบโตสำคัญ
- **งานหลัก:** เตรียมข้อมูล พัฒนา/ประเมินโมเดล สร้าง API นำขึ้นใช้งานและติดตามผล
- **รายวิชาหลัก:** EN-131-106, EN-131-105, EN-131-107 และ EN-132-107
- **Portfolio ขั้นต่ำ:** end-to-end ML system ที่ทำซ้ำได้ มี API, automated test, deployment และ monitoring
- **คำค้นงาน:** `AI Engineer`, `Machine Learning Engineer`, `Junior ML Engineer`, `Applied AI Engineer`

### T3-2 วิศวกรข้อมูล

**Data Engineer — Market Core**

- **เหตุผลที่เลือก:** TDRI พบ Data Engineer/System Engineer 2,037 ตำแหน่งในไตรมาส 2/2568 เพิ่ม 25.6% ต่อปี และข้อมูลเป็นโครงสร้างพื้นฐานของทุกระบบ AI
- **งานหลัก:** ออกแบบ database, ETL/ELT, batch/streaming pipeline, orchestration, data quality และ governance
- **รายวิชาหลัก:** EN-131-107 และวิชาวิศวกรรมข้อมูลขั้นสูงและการวางท่อข้อมูล
- **Portfolio ขั้นต่ำ:** pipeline จากหลายแหล่งพร้อม orchestration, tests, lineage/quality และ dashboard หรือ downstream ML use case
- **คำค้นงาน:** `Data Engineer`, `ETL Developer`, `Data Platform Engineer`, `Big Data Engineer`, `Analytics Engineer`

### T3-3 วิศวกรซอฟต์แวร์ AI และแอปพลิเคชัน Generative AI

**AI Software and Generative AI Application Engineer — Market/Future**

- **เหตุผลที่เลือก:** Software/Application Developer เป็นงานเติบโตสูงตาม WEF/BLS และตลาดไทยเริ่มต้องการ Prompt, RAG, LangChain และ Responsible AI เพิ่มขึ้น จึงรวมฐานซอฟต์แวร์ที่มีตลาดจริงกับ GenAI ที่เป็นอนาคต
- **งานหลัก:** พัฒนา AI application, backend/API, RAG/LLM workflow, evaluation, guardrail, cloud deployment และ integration
- **รายวิชาหลัก:** EN-132-107, EN-132-108, วิชา Generative AI, Cloud Microservices และ AI Software QA
- **Portfolio ขั้นต่ำ:** AI application หรือ RAG system ที่มี test/evaluation, citation, access control, cost/latency และ safety guardrails
- **คำค้นงาน:** `AI Software Engineer`, `AI Application Developer`, `Generative AI Engineer`, `LLM Engineer`, `RAG Developer`, `Backend AI Engineer`

## อาชีพภาพรวมหลักสูตร — ใช้ได้กับทุก Track

### C1 นักวิทยาศาสตร์ข้อมูล / นักวิเคราะห์ข้อมูล

**Data Scientist / Data Analyst — Market Core**

- **เหตุผลที่เลือก:** เป็นกลุ่มประกาศงาน AI ที่ใหญ่ที่สุดในข้อมูล TDRI จำนวน 2,618 ตำแหน่งในไตรมาส 2/2568 และทุก Track มีข้อมูลเฉพาะโดเมนให้วิเคราะห์
- **ความต่างตาม Track:** T1 วิเคราะห์ข้อมูลฟาร์ม/พื้นที่; T2 วิเคราะห์การผลิต/คุณภาพ/พลังงาน; T3 วิเคราะห์ผลิตภัณฑ์ ลูกค้า หรือระบบดิจิทัล
- **ทักษะร่วม:** SQL, Python, statistics, ML, visualization, communication และ domain knowledge
- **Portfolio ขั้นต่ำ:** ตั้งโจทย์ธุรกิจหรือวิศวกรรม วิเคราะห์ข้อมูล สร้างโมเดล/visualization และเสนอการตัดสินใจที่ตรวจสอบได้

### C2 วิศวกรประยุกต์และโซลูชัน AI

**AI Application / Solutions Engineer — Market Core**

- **เหตุผลที่เลือก:** TDRI พบกลุ่ม AI Technical User 1,900 ตำแหน่งในไตรมาส 2/2568 งานกลุ่มนี้ต้องแปลงความต้องการผู้ใช้เป็น solution เชื่อมข้อมูล โมเดล software/hardware และนำไปใช้จริง
- **ความต่างตาม Track:** T1 โซลูชันเกษตร; T2 โซลูชันโรงงาน/automation; T3 โซลูชัน software/cloud/enterprise AI
- **ทักษะร่วม:** requirement analysis, system design, prototype, deployment, cost-benefit, communication และ project coordination
- **Portfolio ขั้นต่ำ:** solution proposal + architecture + working prototype + test result + presentation สำหรับผู้ใช้เทคนิคและไม่ใช่เทคนิค
- **คำค้นงาน:** `AI Solutions Engineer`, `Application Engineer`, `Implementation Engineer`, `Technical Consultant`, `Pre-sales Engineer AI`

### C3 วิศวกรระบบ IoT และ Edge AI

**IoT and Edge AI Systems Engineer — Future/Sector Critical**

- **เหตุผลที่เลือก:** Sensor networks, edge computing และ AI เป็นฐานร่วมของเกษตรอัจฉริยะ โรงงานอัจฉริยะ และผลิตภัณฑ์ connected systems; WEF ระบุ sensor networks และ robotics เป็นเทคโนโลยีที่กำลังเปลี่ยนงานเกษตรและการผลิต
- **ความต่างตาม Track:** T1 ระบบ sensor ในฟาร์ม; T2 IIoT/OT integration; T3 device–cloud platform และ AI service
- **ทักษะร่วม:** electronics, embedded/edge, MQTT/industrial protocols, networking, cloud, cybersecurity และ model optimization
- **Portfolio ขั้นต่ำ:** sensor-to-edge-to-cloud system ที่มี offline handling, monitoring, security และผลทดสอบ latency/reliability
- **คำค้นงาน:** `IoT Engineer`, `Edge AI Engineer`, `Embedded AI Engineer`, `IIoT Engineer`, `IoT Solutions Engineer`
