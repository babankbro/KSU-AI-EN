# ข้อมูลหลักสูตรปัจจุบัน พ.ศ. 2570

> หลักสูตรวิศวกรรมศาสตรบัณฑิต สาขาวิชาวิศวกรรมปัญญาประดิษฐ์และระบบอัจฉริยะ  
> คณะวิศวกรรมศาสตร์และเทคโนโลยีอุตสาหกรรม มหาวิทยาลัยกาฬสินธุ์

## สถานะข้อมูล

หน้านี้เป็นจุดเริ่มต้นสำหรับข้อมูลที่ถอดและสังเคราะห์จากเล่มหลักสูตร Word ฉบับแก้ไขล่าสุดที่ได้รับเมื่อ 19 กรกฎาคม 2569 โดยยึดข้อความในต้นฉบับเป็นหลัก และแยกข้อสังเกตที่ยังต้องยืนยันไว้ต่างหาก

## ข้อมูลสำคัญโดยย่อ

| รายการ | ข้อมูลปัจจุบัน |
|---|---|
| ชื่อหลักสูตร | วิศวกรรมศาสตรบัณฑิต สาขาวิชาวิศวกรรมปัญญาประดิษฐ์และระบบอัจฉริยะ |
| สถานะ | หลักสูตรใหม่ พ.ศ. 2570 ซึ่งพัฒนาต่อยอดจากหลักสูตรเดิม |
| หน่วยกิตรวม | **133 หน่วยกิต** (ยืนยันแล้ว · ต้นฉบับ DOCX เดิมระบุ 130 หน่วยกิต) |
| PLO มาตรฐานกลางของ Vault | 7 ข้อ เทียบเคียง ABET SO1–SO7 |
| PLO ในต้นฉบับเดิม | 5 ข้อ เก็บไว้เป็นหลักฐานประวัติ |
| แขนงวิชา | 3 แขนง |
| ชื่อแขนงวิชา | เกษตรอัจฉริยะ · ปัญญาประดิษฐ์ภาคอุตสาหกรรม · นวัตกรรมปัญญาประดิษฐ์ระดับองค์กร |
| อุตสาหกรรมเป้าหมาย | อ้อยและน้ำตาล ข้าว มันสำปะหลัง และอุตสาหกรรมเกี่ยวเนื่อง |
| รูปแบบการเรียนรู้ | OBE, Experiential Learning, Workshop, Project และสหกิจศึกษา |

## ความสัมพันธ์กับข้อมูลเดิม

เอกสารทุกชุดใน Vault ให้ใช้ [[../01_Labor_Market_Research/10_PLOs_ABET_Design|PLO 7 ข้อและรายละเอียดการเทียบเคียง ABET]] เป็นถ้อยคำมาตรฐานกลาง ส่วน [[02_PLOs_5|PLO 5 ข้อ]] เป็นข้อมูลที่ถอดจากต้นฉบับเดิมและคงไว้เพื่อแสดงที่มาของการปรับจาก 5 เป็น 7 ข้อ
