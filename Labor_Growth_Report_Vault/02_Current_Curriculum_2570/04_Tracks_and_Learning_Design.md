# แขนงวิชาและแนวทางจัดการเรียนรู้

## โครงสร้าง 3 แขนงวิชา

หลักสูตรกำหนดรายวิชาเลือกเฉพาะแขนง (Selective Track) จำนวนไม่น้อยกว่า 15 หน่วยกิต โดยนักศึกษาเลือกเรียนตามแขนงที่สนใจ

ชื่อแขนงวิชามาตรฐานที่ใช้ทั้งหลักสูตร ได้แก่ **เกษตรอัจฉริยะ ปัญญาประดิษฐ์ภาคอุตสาหกรรม และนวัตกรรมซอฟต์แวร์ปัญญาประดิษฐ์**

## แขนงที่ 1: เกษตรอัจฉริยะ

**Smart Agriculture**

เน้นการนำ AI และระบบอัจฉริยะไปใช้ตลอดห่วงโซ่การผลิตเกษตรและอุตสาหกรรมแปรรูป ตั้งแต่การตรวจวัดในแปลง การวางแผนการผลิต ไปจนถึงการจัดการหลังการเก็บเกี่ยว โดยใช้ **ข้าว อ้อย และมันสำปะหลัง** เป็นบริบทสำคัญของแขนงวิชาเกษตรอัจฉริยะ

ขอบเขตสำคัญ:

- เกษตรแม่นยำและระบบฟาร์มอัจฉริยะ
- IoT เซนเซอร์ และระบบควบคุมสภาพแวดล้อม
- โดรน ภาพถ่ายทางอากาศ และ Remote Sensing
- Computer Vision สำหรับโรคพืชและคุณภาพผลผลิต
- หุ่นยนต์และระบบอัตโนมัติทางการเกษตร
- การวิเคราะห์ข้อมูลพืชเศรษฐกิจและปศุสัตว์
- เทคโนโลยีข้าว อ้อย มันสำปะหลัง และอุตสาหกรรมแปรรูปที่เกี่ยวข้อง

## แขนงที่ 2: ปัญญาประดิษฐ์ภาคอุตสาหกรรม

**Industrial AI**

เน้นการบูรณาการ AI กับระบบควบคุม กระบวนการผลิต และ **ระบบอัตโนมัติในโรงงาน** โดยเฉพาะอุตสาหกรรมแปรรูปข้าว อ้อย และมันสำปะหลัง

ขอบเขตสำคัญ:

- PLC/SCADA และระบบอัตโนมัติ
- ระบบอัตโนมัติในโรงงานและการบูรณาการระบบควบคุม
- Industrial Computer Vision และการตรวจสอบคุณภาพ
- Predictive Maintenance
- Digital Twin และการจำลองกระบวนการ
- หุ่นยนต์อุตสาหกรรมและระบบขนถ่ายวัสดุ
- การเพิ่มประสิทธิภาพกระบวนการผลิตและคลังสินค้า

## แขนงที่ 3: นวัตกรรมซอฟต์แวร์ปัญญาประดิษฐ์

**Artificial Intelligence Software Innovation**

เน้นการพัฒนาซอฟต์แวร์ ผลิตภัณฑ์ และโครงสร้างพื้นฐาน AI ที่สามารถนำไปใช้งานจริง ขยายระบบได้ และสร้างคุณค่าให้กับ **ธุรกิจเทคโนโลยีระดับองค์กร**

ขอบเขตสำคัญ:

- Data Engineering และ Real-time Data Pipeline
- Generative AI และการพัฒนาแอปพลิเคชัน LLM
- MLOps, CI/CD และการบริหารวงจรชีวิตโมเดล
- Cloud-native และ Microservices
- AI Software Testing, Bias, Fairness และ Security
- UX/UI และ Explainable AI
- การออกแบบผลิตภัณฑ์และธุรกิจเทคโนโลยี
- สถาปัตยกรรมโซลูชันและธุรกิจเทคโนโลยีระดับองค์กร

## รูปแบบการเรียนรู้ร่วม

นักศึกษาทุกแขนงเรียนพื้นฐานทางวิศวกรรมและ AI ร่วมกัน ก่อนพัฒนาความเชี่ยวชาญผ่าน:

1. รายวิชา Basic Core Track ที่เชื่อมทั้ง 3 บริบท
2. รายวิชาเลือกเฉพาะแขนง
3. Workshop ที่สร้างต้นแบบจากโจทย์จริง
4. สัมมนาและโครงงานวิศวกรรม AI
5. สหกิจศึกษาในสถานประกอบการ

## เส้นทางอาชีพ

รายการอาชีพ ระดับความพร้อมสำหรับบัณฑิตใหม่ ทักษะ และ Portfolio ที่แนะนำของแต่ละแขนง ดู [[../01_Labor_Market_Research/11_Career_Paths_by_Track|เส้นทางอาชีพจำแนกตาม 3 Tracks]]

รายการย่อสำหรับใช้สื่อสารและประชาสัมพันธ์หลักสูตร ดู [[../01_Labor_Market_Research/12_Priority_Careers_12|12 อาชีพเป้าหมายสำคัญ]]

## ความสัมพันธ์กับ PLO
