# ผลลัพธ์การเรียนรู้รายวิชาและการจัดการเรียนรู้ที่สอดคล้อง

> [!warning] เอกสารนี้เป็นฉบับ 133 หน่วยกิตและใช้ชุดรหัสรายวิชาก่อนการปรับโครงสร้าง
> ฉบับที่ใช้กับเล่มหลักสูตรปัจจุบันอยู่ที่ [[../08_TQF2_Book_Revisions/16_Section4_6_CLO_Mapping|หมวดที่ 4 หัวข้อ 4.6 ฉบับ 125 หน่วยกิต]] ซึ่งสร้างจากข้อมูลรายวิชาโดยอัตโนมัติและครอบคลุมวิชาชีพเลือกครบทุกรายวิชา

> หลักสูตรวิศวกรรมปัญญาประดิษฐ์และระบบอัจฉริยะ พ.ศ. 2570
> ฉบับปรับตามกลุ่มวิชาพื้นฐานและปฏิบัติการทางวิศวกรรม 10 วิชา กลุ่มวิชาแกนปัญญาประดิษฐ์และระบบอัจฉริยะ 8 วิชา และกลุ่มวิชาชีพบังคับ 9 วิชา
> สถานะ: ร่างเพื่อทวนสอบ — กลุ่มวิชาชีพบังคับ 27 หน่วยกิต และกลุ่มวิชาชีพเลือก 15 หน่วยกิต รวมทั้งหลักสูตร **133 หน่วยกิต ซึ่งเป็นยอดที่ยืนยันแล้ว** และใช้ชุดรหัสรายวิชาปัจจุบันทั้งเอกสาร
> ทวนสอบความสัมพันธ์ระหว่างทักษะ ทักษะย่อย PLO YLO และ CLO ตามคำอธิบายรายวิชาฉบับล่าสุด ณ วันที่ 29 กรกฎาคม 2569

เอกสารนี้กำหนดผลลัพธ์การเรียนรู้รายวิชา (CLO) ที่สามารถวัดและประเมินได้ พร้อมเชื่อมโยง **YLO → PLO → ทักษะ H/S → AISK01–09 → หลักฐานการประเมิน** ให้สอดคล้องกับคำอธิบายรายวิชาใน [[../04_Course_Descriptions_2570/00_Course_Descriptions_Home|คำอธิบายรายวิชา พ.ศ. 2570]]

## 1. หลักการออกแบบและวิธีอ่าน

- ระดับ **I** = ขั้นเริ่มต้น, **R** = ขั้นเสริมสร้าง, **M** = ขั้นบรรลุผล
- CLO ใช้คำกริยาที่สังเกตได้ เช่น วิเคราะห์ ออกแบบ พัฒนา ทดสอบ ประเมิน สื่อสาร และส่งมอบ
- การระบุว่า “ปิดช่องว่าง” ต้องมีทั้งรายวิชาที่รับผิดชอบ CLO และหลักฐานการประเมิน มิใช่เพียงปรากฏเป็นหัวข้อในคำอธิบายรายวิชา
- กลุ่มวิชาพื้นฐานวิศวกรรมรับผิดชอบความรู้ด้านระบบกายภาพ การคำนวณ การสร้าง และการประกอบ
- กลุ่มวิชาแกนปัญญาประดิษฐ์รับผิดชอบแบบจำลอง ข้อมูล ซอฟต์แวร์ ระบบคลาวด์ และโครงสร้างพื้นฐาน
- กลุ่มวิชาชีพบังคับรับผิดชอบการวิเคราะห์โจทย์ การสร้างคุณค่า การตัดสินใจ ความรู้เฉพาะบริบท และการบูรณาการระบบ
- โครงงานวิศวกรรมและสหกิจศึกษาเป็นจุดประเมินขั้นบรรลุผล โดยต้องมีหลักฐานตามลำดับ **ข้อกำหนด → การออกแบบ → การสร้างและบูรณาการ → การทดสอบและประเมิน → คุณค่าและ BCG → การยอมรับและส่งมอบ**

### เกณฑ์แยก PLO ที่ใช้ทวนสอบ

| PLO | ใช้เมื่อ CLO มีหลักฐานโดยตรง | ไม่ใช้แทนกัน |
|---|---|---|
| PLO1 | ระบุ/สร้างแบบจำลอง/วิเคราะห์สาเหตุและแก้ปัญหาวิศวกรรม | ไม่ใช่เพียงสร้างชิ้นงานตามขั้นตอน |
| PLO2 | ออกแบบหรือบูรณาการตามข้อกำหนดและข้อจำกัด | ไม่ใช่เพียงวิเคราะห์ข้อมูล |
| PLO3 | สื่อสารแก่ผู้รับสารที่ระบุผ่านรายงาน การนำเสนอ แผงสรุปข้อมูล หรือสื่อดิจิทัล | ไม่ใช่เพียงจัดทำเอกสารภายใน |
| PLO4 | ประเมินจริยธรรม กฎหมาย ธรรมาภิบาล ความมั่นคงปลอดภัย มาตรฐาน ความปลอดภัย หรือผลกระทบ | ไม่ใช้กับการทดสอบคุณภาพที่ไม่มีมิติด้านความรับผิดชอบ |
| PLO5 | แสดงบทบาทในทีม กำหนดเป้าหมาย วางแผน บริหารความเสี่ยง จัดการข้อขัดแย้ง หรือแสดงความรับผิดชอบต่อผลลัพธ์ | ไม่ใช่เพียงเข้าร่วมงานกลุ่ม |
| PLO6 | ออกแบบการทดลอง เก็บข้อมูล วิเคราะห์ความไม่แน่นอน และตีความสมรรถนะ คุณภาพ ความน่าเชื่อถือ หรือความปลอดภัย | ไม่ใช่เพียงคำนวณผลตอบแทนการลงทุนหรือจัดทำแผงสรุปข้อมูล |
| PLO7 | แสวงหาความรู้ใหม่หรือพัฒนานวัตกรรม ผลิตภัณฑ์ หรือบริการที่สร้างคุณค่าหลายมิติ | ไม่ใช่เพียงนำระบบขึ้นใช้งานหรือส่งมอบระบบ |

### รหัสชุดทักษะ

| รหัส | ชุดทักษะ |
|---|---|
| AISK01 | แกนวิศวกรรมปัญญาประดิษฐ์ |
| AISK02 | วิศวกรรมเกษตรอัจฉริยะ |
| AISK03 | อุตสาหกรรมอัจฉริยะและระบบอัตโนมัติ |
| AISK04 | ระบบตรวจวัด การประมวลผลที่ขอบเครือข่าย และระบบไซเบอร์กายภาพ |
| AISK05 | การรับรู้ การพยากรณ์ และการตัดสินใจด้วยปัญญาประดิษฐ์ |
| AISK06 | ปัญญาประดิษฐ์เชิงสร้าง ระบบเอเจนต์ และการทำงานร่วมระหว่างมนุษย์กับปัญญาประดิษฐ์ |
| AISK07 | ปัญญาประดิษฐ์ที่รับผิดชอบ ความมั่นคงปลอดภัย ธรรมาภิบาล และการรับรองระบบ |
| AISK08 | การสื่อสาร การทำงานเป็นทีม ภาวะผู้นำ และความเป็นผู้ประกอบการ |
| AISK09 | ข้อกำหนด สถาปัตยกรรม การบูรณาการ และการส่งมอบระบบ |

> **หลักการนับภาระ:** รหัส AISK ตัวแรกในแต่ละ CLO คือ **ชุดทักษะเจ้าภาพหลัก** ซึ่งรับผิดชอบกำหนดเกณฑ์และหลักฐานประเมิน ส่วนรหัสถัดไปเป็น **ชุดทักษะสนับสนุน** จึงไม่นับเป็นภาระเต็มซ้ำอีกครั้ง

### 7.1 ฐานวิศวกรรมที่ต้องติดตามเพิ่มจาก HS1–HS20

HS1–HS20 เป็นทักษะอาชีพด้านปัญญาประดิษฐ์และระบบอัจฉริยะ จึงไม่ควรนำทักษะวิศวกรรมกายภาพไปซ่อนหรือบังคับรวมไว้ใน H ข้อใดข้อหนึ่ง เอกสารนี้จึงกำหนดรหัสประกอบ **EF1–EF6 สำหรับฐานทักษะวิศวกรรม** เพื่อสอบย้อนกลับข้อเสนอของผู้ทรงคุณวุฒิ โดยไม่เปลี่ยนบัญชีทักษะหลัก HS1–HS20

| รหัส | ฐานทักษะย่อย | PLO หลัก | CLO/รายวิชาเจ้าภาพ | สถานะ |

## 12. เงื่อนไขก่อนนำไปใช้ในเล่มหลักสูตร

1. ยอดรวมที่ใช้จริงคือ **125 หน่วยกิต** ตามเล่มฉบับผ่านคณะ หัวข้อ 4.1 — ตัวเลข 133 ในร่างเก่าถูกยกเลิกแล้ว ดู [[../08_TQF2_Book_Revisions/19_Approved_Book_Identity_and_Structure|เล่มฉบับผ่านคณะ]]
2. ยืนยันเงื่อนไขก่อนเรียนของ EN-132-201 ซึ่งแผนการเรียนวางเปิดสอนในชั้นปีที่ 2 ภาคการศึกษาที่ 4
3. ตรวจ [[../03_OBE_PLO_Design_2570/07_Curriculum_PLO_Mapping|เมทริกซ์รายวิชากับ PLO]] และ [[../03_OBE_PLO_Design_2570/08_Study_Plan_and_Dependencies|แผนการเรียน 8 ภาคการศึกษา]] ให้ใช้ชุดรหัสเดียวกันทุกตาราง
4. จัดทำเกณฑ์ประเมินร่วมสำหรับข้อกำหนด การบูรณาการระบบ ความปลอดภัย ธรรมาภิบาล BCG และคาร์บอน การทดสอบการยอมรับของผู้ใช้ และการส่งมอบ
5. กำหนดตัวชี้วัดผลการดำเนินงานเฉพาะแขนงในโครงงานและสหกิจศึกษา แม้วิชาชีพบังคับทั้ง 9 วิชาจะเป็นพื้นฐานร่วม
6. กำหนด CLO เฉพาะรายวิชาสำหรับวิชาเลือกทั้ง 5 วิชาตามเกณฑ์การเลือกแบบตะกร้า โดยต้องทำให้ผู้เรียนมีความลึกระดับ L4 อย่างน้อยหนึ่งกลุ่มใน HS10/HS12/HS18/HS20 หรือทักษะเฉพาะบริบทของแขนง
7. ตรวจสอบความพร้อมของผู้สอนและห้องปฏิบัติการด้านระบบกำลังของไหล PLC/SCADA ระบบความร้อนและกระบวนการ หุ่นยนต์และการมองเห็น อากาศยานไร้คนขับและปัญญาประดิษฐ์เชิงพื้นที่ ตลอดจนระบบคลาวด์และการประมวลผลที่ขอบเครือข่าย
8. ใช้รหัส EF1–EF6 ในเมทริกซ์หลักสูตรและระเบียนทักษะ เพื่อให้ฐานทักษะวิศวกรรมตามข้อเสนอของผู้ทรงคุณวุฒิมีเจ้าภาพและหลักฐานประเมินอย่างชัดเจน
