# ตารางสรุปการเชื่อมโยงผลลัพธ์การเรียนรู้รายวิชา (CLOs) สู่ผลลัพธ์ระดับสูง

> หลักสูตรวิศวกรรมปัญญาประดิษฐ์และระบบอัจฉริยะ พ.ศ. 2570 — ร่างเพื่อพิจารณา
> แตกจากขั้นที่หก (Constructive Alignment) ใน [[../03_OBE_PLO_Design_2570/07_Curriculum_PLO_Mapping|Curriculum–PLO Mapping]] · ผูกกับ [[09_Yearly_Learning_Outcomes|Sub-YLO 16 ข้อ]] · [[../03_OBE_PLO_Design_2570/04_PLOs_7_OBE|PLO 7 ข้อ]] · [[11_Skill_Set_Matrix_and_KSA|Skill Set Matrix EN-AISK01–08]]

ตารางนี้แสดงรายละเอียดการเชื่อมโยงของผลลัพธ์การเรียนรู้ในแต่ละรายวิชา (Course Learning Outcomes: CLOs) ไปยังผลลัพธ์การเรียนรู้รายปี (Year Learning Outcomes: YLOs) และผลลัพธ์การเรียนรู้ระดับหลักสูตร (Program Learning Outcomes: PLOs) พร้อมระบุ **ความรู้–ทักษะ–ทัศนคติ (KSA) ที่แต่ละรายวิชารับผิดชอบ** และ **ชุดทักษะ (Skill Set) ที่รายวิชานั้นป้อนเข้า** เพื่อให้เห็นภาพรวมของการพัฒนาผู้เรียนอย่างเป็นระบบตลอดหลักสูตร

## วิธีอ่านเอกสาร

แต่ละรายวิชาประกอบด้วย 2 ส่วน:

1. **กล่อง KSA ที่รับผิดชอบ** — 🧠 **K (Knowledge)** หัวข้อความรู้ที่ต้องสอน · 🛠️ **S (Skill)** ทักษะที่ต้องฝึก พร้อมชี้ **Skill Set (AISK) และกลุ่ม (G)** ที่รายวิชาป้อนเข้า · ❤️ **A (Attitude)** ทัศนคติที่ต้องปลูกฝัง
2. **ตาราง CLO → YLO → PLO (ระดับ)** — ผลลัพธ์การเรียนรู้ที่วัดได้และเส้นทางการ trace กลับสู่ผลลัพธ์ระดับหลักสูตร

> [!tip] ความสัมพันธ์ KSA ↔ CLO
> **K + S + A** คือ "สิ่งที่รายวิชาต้องรับผิดชอบพัฒนา" ตาม PLO ที่ได้รับมอบหมาย ส่วน **CLO** คือ "ข้อความที่วัดผลได้" ซึ่งกลั่นมาจาก KSA เหล่านั้น — ใช้กล่อง KSA เป็นแนวทางออกแบบการสอนและวิธีวัดผลใน มคอ.3

## หลักการออกแบบ CLO

1. **จำนวน CLO ต่อวิชา:** วิชาทฤษฎี/ปฏิบัติ 3 หน่วยกิต กำหนด 3 CLOs · วิชาปฏิบัติการ/สัมมนา 1 หน่วยกิต กำหนด 1–2 CLOs · Capstone/สหกิจบูรณาการหลาย PLO
2. **CLO วัดได้ (Measurable):** ขึ้นต้นด้วยคำกริยาเชิงพฤติกรรมตาม Bloom's Taxonomy (อธิบาย/คำนวณ/วิเคราะห์/ออกแบบ/พัฒนา/ประเมิน/สร้าง) และสอดคล้องกับวิธีวัดผลของรายวิชา
3. **ระดับพัฒนาการ (Developmental Level):**
   - **I (Introduce)** — แนะนำ/เริ่มพัฒนา · โดยหลักอยู่ชั้นปีที่ 1
   - **R (Reinforce)** — เสริมย้ำ/ประยุกต์ · โดยหลักอยู่ชั้นปีที่ 2–3
   - **M (Mastery)** — ประเมินระดับปลายทาง/บูรณาการ · โดยหลักอยู่โครงงานและสหกิจปีที่ 3–4
   - *(เทียบกับสัญกรณ์ I/M/F ในบางแม่แบบ: I=Introduce, M(R)=กำลังพัฒนา, F(M)=ชำนาญ)*
4. **การกำหนดระดับ** อ้างตาราง`YLO ↔ PLO` ใน [[09_Yearly_Learning_Outcomes#3-ylo-plo-และระดับการพัฒนา]]: ปี 1 = I · ปี 2 = R · ปี 3 = PLO2/5/6 เป็น M ที่เหลือ R · ปี 4 = M
5. **KSA ผูกกับ Skill Set:** ทักษะ (S) ของทุกรายวิชาชี้ไปยังชุดทักษะ **EN-AISK01–08** และกลุ่ม **G1–G6** ใน [[11_Skill_Set_Matrix_and_KSA]] เพื่อให้สามารถออก **Skill Transcript** ได้จากผลการเรียนรายวิชาโดยตรง
