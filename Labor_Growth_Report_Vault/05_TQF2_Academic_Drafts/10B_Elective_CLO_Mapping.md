# ผลลัพธ์การเรียนรู้รายวิชาชีพเลือก (CLO)

> [!important] เอกสารนี้เป็นแหล่งอ้างอิงหลักของ CLO วิชาชีพเลือก
> คำสั่ง `SYNC_CLO=1 npm run sync:curriculum` อ่านตารางในเอกสารนี้ไปสร้าง `cloRevisionData.js`
> ซึ่งไปแทนที่ค่าใน `cloData.js` อีกชั้น — แก้ที่นี่แล้วสร้างใหม่ อย่าแก้ไฟล์ปลายทางโดยตรง
> คู่กับ [[10_Course_Learning_Outcomes_CLO_Mapping|CLO ของรายวิชาบังคับ]] ซึ่งครอบคลุมรายวิชาบังคับ 34 รายวิชา

> [!warning] ระดับ Bloom เป็นฉบับร่าง · คอลัมน์หลักฐานยังว่าง
> **ระดับ Bloom** ร่างครบทั้ง 171 CLO ด้วย `npm run draft:bloom` ตามกติกาใน
> [[../03_OBE_PLO_Design_2570/03_Target_Skills#3.3 ระดับตามแนวทาง Bloom|§3.3 และ §3.3b]] —
> คำกริยานำเป็นระดับตั้งต้น ยกขึ้นเมื่อ CLO รับผิดชอบ PLO ระดับ M ไล่ระดับขึ้นภายในรายวิชา
> ใช้อย่างน้อยสองระดับ และเพดานที่ B5 เพราะวิชาชีพเลือกเปิดชั้นปีที่ 3–4
> สมุดรหัสระบุว่า **ระดับตัดสินจากบริบทของโจทย์ ไม่ใช่จากคำกริยา** ตัวเลขชุดนี้จึงเป็นจุดตั้งต้น
> ที่คณะกรรมการบริหารหลักสูตรต้องทวนสอบรายข้อก่อนเปิดสอน ไม่ใช่ค่าที่อนุมัติแล้ว
>
> **คอลัมน์หลักฐาน** ยังว่างทั้งหมด ต้องกำหนดพร้อมกับ มคอ.3 ของแต่ละรายวิชา

**การกระจายระดับ Bloom ฉบับร่าง** — B2 จำนวน 11 · B3 จำนวน 35 · B4 จำนวน 98 · B5 จำนวน 27

รวม **57 รายวิชา** · รูปแบบตารางตรงกับเอกสาร CLO ของรายวิชาบังคับ
