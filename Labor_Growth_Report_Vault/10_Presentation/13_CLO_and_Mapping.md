# หน้า 13 · ⑧ CLO 288 ข้อ และ Curriculum Mapping

> **CLO คือจุดที่หลักสูตรสัมผัสกับนักศึกษาจริง — ทุกอย่างเหนือขึ้นไปเป็นเพียงคำสัญญาจนกว่าจะมี CLO รองรับ**

## สาระบนสไลด์

| ข้อมูล | จำนวน |
|---|--:|
| CLO ทั้งหมด | 288 |
| CLO → PLO | 426 ความสัมพันธ์ |
| CLO → Sub-YLO | 319 ความสัมพันธ์ |
| CLO → รหัส KSA | 963 ความสัมพันธ์ |
| CLO → ชุดทักษะ AISK | 211 ความสัมพันธ์ |
| รายวิชา → PLO | 293 ความสัมพันธ์ |

### ตารางที่ใช้ในเล่ม มคอ.2

| หัวข้อในเล่ม | เนื้อหา | สร้างจาก |
|---|---|---|
| 4.5 Curriculum Mapping | รายวิชา × PLO พร้อมระดับ I/R/M | สร้างอัตโนมัติ |
| 4.6 CLO Mapping | CLO × PLO ราย CLO | สร้างอัตโนมัติ |
| 4.7 Skill Set Coverage | รายวิชา × ชุดทักษะ AISK01–09 | สร้างอัตโนมัติ |

> [!important] ทำไมต้องมีทั้ง 4.5 และ 4.6
> **4.5 หยาบเกินไปสำหรับการตรวจ** — บอกได้แค่ว่าวิชานี้เกี่ยวกับ PLO3
> **4.6 คือชั้นที่ให้คะแนนได้จริง** — บอกว่า CLO ข้อไหนของวิชานั้นป้อนเข้า PLO3 ที่ระดับใด
> ผู้ตรวจ AUN-QA จะดู 4.6 ไม่ใช่ 4.5

> [!tip] เล่าอย่างไร (≈2.5 นาที)
> 1. นิยามให้สั้นที่สุด — *"CLO คือสิ่งที่นักศึกษาต้องทำได้เมื่อจบวิชาหนึ่ง และเป็นสิ่งเดียวในสายธารทั้งหมดที่มีคะแนนจริงผูกอยู่"*
> 2. เล่าความหนาแน่น — *"288 CLO เชื่อมขึ้นไปหา PLO 426 เส้น เชื่อมกับ KSA 963 เส้น ตัวเลขนี้บอกว่าหลักสูตรถูกร้อยเข้าด้วยกันจริง ไม่ใช่แค่วางตารางไว้ข้างกัน"*
> 3. เน้นความต่างของ 4.5 กับ 4.6 — นี่คือจุดที่ทำให้กรรมการเชื่อว่าเราเข้าใจ OBE จริง
> 4. ปิดด้วยการสร้างอัตโนมัติ — *"ตารางทั้งสามในเล่มไม่ได้พิมพ์มือ สร้างจากข้อมูลชุดเดียวกัน ถ้าแก้ CLO หนึ่งข้อ ทั้งสามตารางเปลี่ยนพร้อมกัน"*

> [!question] คำถามที่มักถูกถาม
> **ถาม:** วิชาชีพเลือกที่ไม่ได้เปิดทุกปี มี CLO ครบหรือไม่
> **ตอบ:** CLO 288 ข้อครอบคลุมวิชาบังคับและกิจกรรมบังคับเป็นหลัก ส่วนคลังวิชาชีพเลือกใช้การเชื่อมผ่าน **ชุดทักษะ** แทน — จึงนับเข้าความครอบคลุมได้โดยไม่ต้องบังคับให้ทุกวิชาในคลังมี CLO ครบก่อนเปิดสอน
