# หน้า 6 · รายวิชา 97 วิชา และระบบรหัสที่อ่านความหมายได้

> **รหัสวิชาไม่ใช่เลขที่วิ่งไปเรื่อย ๆ — อ่านรหัสแล้วรู้ทันทีว่าเป็นกลุ่มวิชาอะไร ชั้นปีไหน และอยู่แขนงใด**

## โครงสร้างรหัสวิชา

```
EN - 132 - 305
│    │     │└─ ลำดับวิชาในกลุ่ม
│    │     └── หลักแรก = ชั้นปีที่ควรเรียน (3 = ปี 3)
│    └──────── กลุ่มวิชา
└───────────── คณะวิศวกรรมศาสตร์
```

| คำนำหน้า | กลุ่มวิชา | ช่วงรหัส |
|---|---|---|
| `GE-010` / `GE-020` | ศึกษาทั่วไป บังคับ / เลือก | — |
| `EN-001` | พื้นฐานและปฏิบัติการทางวิศวกรรม | `121–128`, `230` |
| `EN-131` | แกน AI บังคับทุกแขนง | `2xx` |
| `EN-132` | วิชาชีพบังคับ | `201`, `302–309` |
| `EN-134` | โครงงานและสัมมนา | `4xx` |
| `EN-135-3xx` | วิชาชีพเลือก (คลัง 57 วิชา) | ดูตารางล่าง |
| `EN-135-401 / 402` | เตรียมสหกิจ / สหกิจศึกษา | — |

### คลังวิชาชีพเลือก 57 วิชา — แบ่งตามแขนง

| ช่วงรหัส | สังกัด |
|---|---|
| `EN-135-301–315` | แขนง 1 · เกษตรอัจฉริยะ |
| `EN-135-316–335` | แขนง 2 · ปัญญาประดิษฐ์ภาคอุตสาหกรรม |
| `EN-135-336–350` | แขนง 3 · นวัตกรรม AI ระดับองค์กร |
| `EN-135-351–357` | ร่วมทุกแขนง — การเรียนรู้ร่วมการทำงานและหัวข้อพิเศษ |

## ข้อมูลที่ผูกกับรายวิชาแต่ละตัว

| ข้อมูล | จำนวนแถวในฐานข้อมูล |
|---|--:|
| รายวิชา | 97 |
| ความสัมพันธ์ก่อน–หลัง | 70 |
| รายวิชา ↔ PLO | 293 |
| รายวิชา ↔ ชุดทักษะ AISK | 290 |
| รายวิชา ↔ รหัส KSA | 2,292 |
| CLO ของรายวิชา | 288 |

> [!tip] เล่าอย่างไร (≈2 นาที)
> 1. โชว์รหัสเดียวแล้วถอดให้ดู — *"ขอรหัสเดียวครับ `EN-132-305` — EN คือวิศวะ 132 คือวิชาชีพบังคับ เลข 3 ตัวแรกคือปีสาม"*
> 2. บอกประโยชน์ — *"ข้อดีคือเวลาเปิดตารางสอน เห็นรหัสก็รู้ทันทีว่าวิชานี้ควรอยู่ปีไหน ถ้ามีวิชารหัส 3 ไปโผล่ปีสอง แปลว่าแผนการเรียนผิด"*
> 3. อธิบายคลังวิชาเลือก — *"ช่วงรหัสของวิชาเลือกถูกจองไว้ตามแขนง จึงเพิ่มวิชาใหม่ในแขนงหนึ่งได้โดยไม่ชนกับแขนงอื่น"*
> 4. ปิดด้วยความเชื่อมโยง — *"และรายวิชาหนึ่งตัวไม่ได้อยู่ลอย ๆ มันผูกกับ PLO ชุดทักษะ และรหัส KSA รวมกว่า 2,800 ความสัมพันธ์ ซึ่งจะเห็นในหน้า 13–15"*

> [!question] คำถามที่มักถูกถาม
> **ถาม:** ทำไมสหกิจศึกษาใช้คำนำหน้า `EN-135` เหมือนวิชาเลือก
> **ตอบ:** เป็นการจองช่วงรหัส `401–402` แยกออกจากช่วงวิชาเลือก `301–357` ไว้ในกลุ่มเดียวกัน เพื่อให้ประสบการณ์ภาคสนามอยู่ในสายรหัสของวิชาประยุกต์ตามแขนง
