# Curriculum Explorer — วิศวกรรม AI และระบบอัจฉริยะ (พ.ศ. 2570)

เว็บแอป **React + Vite** สำหรับนำเสนอโครงสร้างหลักสูตร B.Eng. วิศวกรรมปัญญาประดิษฐ์และระบบอัจฉริยะ มหาวิทยาลัยกาฬสินธุ์ — **แยกจาก Obsidian vault** (ไม่ปนกับไฟล์ .md)

## เครื่องมือวาดกราฟ

ใช้ **[dagre](https://github.com/dagrejs/dagre) + SVG ที่วาดเอง** (ไม่ใช้ React Flow) เพราะ:

- dagre เป็น **layered graph layout** — จัดกล่องเป็นชั้นโดย **ไม่ทับกัน** และเรียงลำดับในแต่ละชั้นเพื่อ **ลดการไขว้ของเส้นให้น้อยที่สุด**
- dagre คืน **bend points ของทุกเส้น** → วาดเส้นตามจุดหักจริง ทำให้ **เส้นเดินอ้อม ไม่ทับกล่อง/ป้ายชื่อวิชา**
- ตรวจสอบแล้ว: **node overlap = 0 ทุกโหมด**

> เคยลอง React Flow v11 แล้วพบบั๊ก `handleBounds` ไม่ผูก ทำให้ edges ไม่ถูกวาด (nodes/markers ปกติแต่ path ว่าง) จึงเปลี่ยนมาวาด SVG เองซึ่งควบคุมได้เต็มที่และไม่มี dependency เพิ่ม

## แท็บในแอป

**① กราฟ** — มี 3 โหมด สลับได้ + ตัวกรอง **สีรายวิชาตามหมวด** + ซูม

| โหมด | แสดง |
|---|---|
| ① Dependencies | วิชาก่อน–หลังเป็นลูกศร — 🔒 Hard (ทึบ) / 💡 Weak (ประ) / 🔁 Co-req (จุด, ลูกศรสองหัว) · **32 กล่อง 45 เส้น** · คลิกวิชาเพื่อไฮไลต์สายก่อน–หลัง |
| ② แยกตามกลุ่ม (หมวด) | คอลัมน์ตามหมวด (พื้นฐานวิศวฯ / แกน AI / บังคับแขนง / โครงงาน / สหกิจ) พร้อมจำนวนวิชา — ไม่แสดงเส้นเพื่อให้อ่านองค์ประกอบชัด |
| ③ แยกตาม PLO | กราฟสองฝั่ง **วิชา → PLO** ที่รับผิดชอบ · **97 เส้น** (ตรงกับยอด ● ในตาราง Curriculum Mapping) · ฮับ PLO บอกจำนวนวิชา |

**สีกล่องวิชา = หมวดวิชา** · ป้าย **ปี N** และ **หมายเลข PLO** อยู่ในกล่องแต่ละวิชา

**② Track → อาชีพ** — สายวิชาของแต่ละ Track ไล่ dependencies จนจบที่ **อาชีพเป้าหมาย 12 ตำแหน่ง**

- เลือกดูรายมุมมอง: **Track 1 / Track 2 / Track 3 / ภาพรวมทุก Track** (ติ๊กรวม "อาชีพภาพรวม 3 ตำแหน่ง" ได้)
- ไล่ย้อน prerequisite chain อัตโนมัติจาก "รายวิชาหลัก" ของแต่ละอาชีพ → เห็นว่าต้องผ่านวิชาใดบ้างกว่าจะถึงอาชีพนั้น
- เส้น 4 ชนิด: Hard / Weak / Co-req ระหว่างวิชา + **เส้นแดง "นำไปสู่อาชีพ"**
- **คลิกกล่องอาชีพ** = โชว์เฉพาะสายวิชาที่นำไปสู่อาชีพนั้น (dim ที่เหลือ) พร้อมเปิดการ์ดรายละเอียด (เหตุผลที่เลือก · รายวิชาหลัก · คำค้นงาน)
- ป้ายสถานะตลาด: **M** Market Core · **S** Sector Critical · **F** Future/Emerging

ที่มาข้อมูลอาชีพ: `../Labor_Growth_Report_Vault/01_Labor_Market_Research/12_Priority_Careers_12.md`

**③ ภาพรวมชั้นปี & YLO** — รายวิชารายปี + YLO1–4 พร้อม PLO progression (I→R→M)
**④ แผนการเรียน** — 8 ภาคเรียน รวม 130 หน่วยกิต
**⑤ คำอธิบายรายวิชา** — **85 วิชา** ค้นหา/กรองได้ · แสดง **คำอธิบายทั้งภาษาไทยและภาษาอังกฤษ** ตรงตามเอกสาร (สลับ ไทย+อังกฤษ / ไทย / English ได้) + วิชาก่อน

## ฟอนต์

ใช้ **IBM Plex Sans Thai** (ตัวอักษรไทย–อังกฤษ) และ **IBM Plex Mono** (รหัสวิชา) โหลดจาก Google Fonts ใน `index.html` — กำหนดผ่านตัวแปร `--font-sans` / `--font-mono` ใน `src/styles.css` · หากใช้งานออฟไลน์ ระบบจะถอยไปใช้ Noto Sans Thai / Segoe UI ตามลำดับ

## วิธีรัน (ต้องมี Node.js ≥ 18)

```bash
cd curriculum-graph
npm install
npm run dev        # เปิด http://localhost:5173
```

Build เป็นไฟล์สแตติกสำหรับ deploy/แชร์:

```bash
npm run build      # ได้โฟลเดอร์ dist/ (เปิด index.html ผ่านเว็บเซิร์ฟเวอร์ได้)
npm run preview
```

## หมายเหตุข้อมูล

- กราฟ Dependencies แสดงเฉพาะ **32 วิชาแกนบังคับ** (มีภาคเรียนแน่นอน) — วิชาเลือกชีพเป็น pool จึงไม่อยู่ในกราฟ แต่มีในแท็บคำอธิบาย
- วิชาเลือกชีพไล่รหัสใหม่ครบแล้ว **45 วิชา ไม่มีรหัสซ้ำ** — แขนง 1 `EN-135-101–115` · แขนง 2 `EN-135-116–130` · แขนง 3 `EN-135-131–145`
- คำอธิบายภาษาอังกฤษ: วิชาที่เอกสารเขียนเฉพาะ (GE, Workshop, EN-135-120/121/122, EN-134-xxx, สหกิจ) เก็บข้อความจริง · วิชาที่เอกสารใช้รูปแบบมาตรฐาน สร้างจากเทมเพลตเดียวกับเอกสารพร้อมบริบทตามหมวด
- ปรับลำดับให้ ML/DL อยู่ภาค 3 (คณิต AI เป็น co-req) เพื่อให้ CV/Cloud ลงภาค 4 ตามสายวิกฤต
