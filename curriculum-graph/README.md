# Curriculum Explorer — วิศวกรรม AI และระบบอัจฉริยะ (พ.ศ. 2570)

เว็บแอป **React + Vite + React Flow** สำหรับนำเสนอโครงสร้างหลักสูตร B.Eng. วิศวกรรมปัญญาประดิษฐ์และระบบอัจฉริยะ มหาวิทยาลัยกาฬสินธุ์ — **แยกจาก Obsidian vault** (ไม่ปนกับไฟล์ .md)

## แท็บในแอป

1. **① กราฟ Dependencies** — โครงข่ายวิชาก่อน–หลังเป็น **ลูกศร** (🔒 Hard / 💡 Weak / 🔁 Co-req) จัดคอลัมน์ตาม **ภาคเรียน 1–8** และ **สีกล่องตามชั้นปี** (เห็นมิติปีชัด) · คลิกวิชาเพื่อไฮไลต์สายวิชาก่อน–หลัง · ลากเลื่อน/ซูม/มินิแมพได้
2. **② ภาพรวมชั้นปี & YLO** — รายวิชารายปี + YLO1–4 พร้อม PLO progression (I→R→M)
3. **③ แผนการเรียน** — 8 ภาคเรียน รวม 130 หน่วยกิต
4. **④ คำอธิบายรายวิชา** — 69 วิชา ค้นหา/กรองได้ (ชื่อไทย–อังกฤษ + คำอธิบายจริง + วิชาก่อน)

ข้อมูลรายวิชา (`src/data.js`) ตรวจสอบจากไฟล์คำอธิบายจริงใน
`../Labor_Growth_Report_Vault/04_Course_Descriptions_2570/`

## วิธีรัน (ต้องมี Node.js ≥ 18)

```bash
cd curriculum-graph
npm install
npm run dev        # เปิด http://localhost:5173
```

Build เป็นไฟล์สแตติกสำหรับ deploy/แชร์:

```bash
npm run build      # ได้โฟลเดอร์ dist/ (เปิด index.html ผ่านเว็บเซิร์ฟเวอร์ได้)
npm run preview
```

## หมายเหตุข้อมูล

- กราฟ Dependencies แสดงเฉพาะ **32 วิชาแกนบังคับ** (มีภาคเรียนแน่นอน) — วิชาเลือกชีพเป็น pool จึงไม่อยู่ในกราฟ แต่มีในแท็บคำอธิบาย
- ต้นฉบับคำอธิบายมี **รหัสซ้ำ EN-135-101 (×3)** และ EN-135-126/127 ชื่อไทยซ้ำ — ในแอปติดป้าย "รหัสซ้ำ" และแสดง 101 / 101ᵃ / 101ᵇ · ควรไล่รหัสใหม่ก่อนใช้ใน มคอ.2
- ปรับลำดับให้ ML/DL อยู่ภาค 3 (คณิต AI เป็น co-req) เพื่อให้ CV/Cloud ลงภาค 4 ตามสายวิกฤต
